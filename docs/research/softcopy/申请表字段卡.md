## 环境与功能描述（供申请表「软件用途/功能/技术特点」栏，可直接摘录）

- **运行的硬件环境**：PC 终端；支持 WebGL2 的显卡（核显/软渲染可运行 low 档）；内存 ≥4 GB。
- **运行的软件环境**：Windows / macOS / Linux 任一操作系统 + 支持 WebGL2 的现代 Chromium 系浏览器（Chrome/Edge 90+）；无后端、无数据库、离线可用。
- **开发该软件的操作系统、开发和运行环境的软件/支持软件**：开发——Node.js 18+/22、npm、Vite 7、TypeScript 5、React 18、three.js、oxlint；基准数据生成——Python 3 + FLORIS 4.6.6（BSD-3）。
- **软件用途**：面向风电场尾流效应管理的研究型数字孪生演示平台，用于风电场功率控制研究、数字孪生方法验证与项目结题演示。
- **软件的主要功能**：三维风电场场景实时渲染（3×3 九机留档 / 1×3 串列演示两布局）；尾流可视化（轮毂高度平面风速场、尾流偏转与衰减）；HUD 运行监视（全场功率、机组状态矩阵、运行指标）；时间轴确定性回放（真实 50 s = 模拟 24 h）；航向角优化七步演示（工况选择、基准查看、三机航向调整 ±30°/5° 步、逐机贪心求解、前后效果复核、可靠性展示、JSON/SVG 材料导出）；画质三档与性能治理；取证冻结（同参数渲染逐像素一致）；41 工况内核-基准对拍展示。
- **软件的技术特点**：① 内置 GCH 高斯尾流物理内核，逐式移植自 FLORIS 4.6.6 开源实现并经 41 工况全字段对拍验证（最大单台功率差 1.25×10⁻¹² kW）；② 逐机贪心航向角优化器（±30° 执行量程、5° 步，1×3 串列工况增益 +22.11%）；③ 纯前端零后端架构，数据构建期打包，离线可用、可复现；④ 演示界面双数据通道（自研内核实时推理 vs FLORIS 基准真值）逐工况透明对拍；⑤ 三道质量闸（静态检查 0 错误 / 161 项功能自检 / 生产构建）常绿。
- **源程序量**：12,040 行（含空行，52 个 ts/tsx 文件 + 自检脚本，2026-10-05 统计；不含空行 11,248 行 ≈ 225 页，按 50 行/页）。
- **鉴别材料说明**：源代码交前 30 页 + 后 30 页（`tools/mk_softcopy_code.py` + `tools/softcopy_code_order.txt` 生成，排版报告见 `output/源代码_60页_草稿.report.md`）；说明文档 = 用户手册（`tools/mk_softcopy_doc.py` 自 `用户手册_v1.md` 生成，共 23 页，< 60 页交全部）。
