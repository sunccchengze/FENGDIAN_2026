# 研究记录入口

`docs/research/` 保存研究轮次、实验、分析、视觉验证、失败尝试和截图证据。这里的记录重点是过程和可复核性，不是把所有内容改写成宣传文案。

## 新记录规则

- 新的研究轮次使用 `roundNN_主题.md`；
- 文件开头写日期、负责人、关联 Issue/PR 和状态；
- 说明输入数据、代码 commit、环境、命令和输出；
- 失败尝试必须保留原因和结论，不能只留下成功路径；
- 截图必须说明机位、参数、尺寸和生成方式；
- 研究日志中的数字若进入 README 或材料，必须在 `docs/evidence/` 建立回溯入口；
- 已经过时的记录不要删除，用状态和 supersede 链接说明它为什么不再是当前口径。

如果新记录与 `viz/` 封板数据或 `twin/` 当前数据口径不同，必须明确标注适用范围，不得用文件名的新旧代替事实审阅。
