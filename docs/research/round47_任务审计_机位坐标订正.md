## 3. 审计发现与订正（本轮唯一实质错误）

**发现**：`docs/research/softcopy/用户手册_v1.md` §4.2 机位表写的是旧串列方案坐标（T01(−100, 0) / T02(100, 0) / T03(300, 0)，x 向 200 m），与实际 1×3 几何不符。四处交叉核验确认**演示侧本身正确**、仅文档转录错误：

1. oracle `tandem3.layout = [(-100, 1272), (-100, 640), (-100, 8)]`（FLORIS x=东 y=北，T01 = 最北 = 上游）；
2. `twin/src/scene/layouts.ts`：`ROWS_Z = [-1272, -640, -8]`，1×3 取 `x = COLS_X[1] = -100`；
3. 演示 step1 卡片：「场景系 +x=东 +z=南；FLORIS 系 x=东 y=北（y=−z）；T01(x=-100, z=-1272) · T02(x=-100, z=-640) · T03(x=-100, z=-8)，行距 632 m (5.02D)」；
4. 截图 `docs/research/img/r44_demo_step1.png` 与卡片代码（`DemoPanel.tsx` L229）一致。

错误来源 = 改造前的三机串列（x 向）草图坐标；9.19 原文不含这些坐标（已 grep 核实，非 9.19 表化石）。

**订正**：

1. 用户手册 §4.2 表 → (−100, 1272) / (−100, 640) / (−100, 8)（FLORIS 系），补行距 632 m = 5.02D 与 oracle/场景系对应说明；
2. 手册 docx 重生成（`docs/research/softcopy/output/用户手册_V1.0_草稿.docx`，新 sha256 `c228e245e4a5618514…`，python-docx 回读校验表内容 ✓；页眉/页脚仍为占位，随 DP0/1/2 一次性替换）；
3. `round46_软著装配_不依赖裁定部分.md` §6 手册行 sha 更新；
4. `round44_演示界面_七步流程.md` §3 表 step1 行的坐标转录由旧方案坐标改为场景系坐标（与截图/卡片一致）。
