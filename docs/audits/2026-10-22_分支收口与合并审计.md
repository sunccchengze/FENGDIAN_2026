## 4. 同名不同内容的 149 个文件：为什么保留主线版本

逐类核对，**没有一类是「主线丢了内容」**：

| 类别 | 数量 | 差异性质 | 判定 |
|---|---|---|---|
| `optimization_control/experiments/**/config.yaml` | 8 | 主线把重复的 `wind_trajectory` 数组压成 YAML 锚点（`&id001` / `*id001`），并把作者本机 `D:\\VSCODE\\大创项目风电\\…` 改写成仓库相对路径 | **保留主线**。用 PyYAML 解析两侧比较：结构差异**只有** `source_hashes` 的键名（Windows 绝对路径 vs 仓库相对路径），sha256 值逐一相同 |
| `experiments/**/*.json`（summary / state / inflow / bank） | ~20 | 同上，路径归一 + 缩进归一 | 保留主线 |
| `experiments/20261022_midterm_figures/*.svg` | 7 | matplotlib 输出的属性顺序 / 空白差异（行数相同） | 保留主线 |
| `optimization_control/surrogate/models/final/*.json` | 7 | 主线是压缩 JSON（1 行），分支是美化 JSON | 保留主线（体积小、语义同） |
| `materials/**/任务说明.md` | 1 | 分支是 OOXML 直出（表格塌成一行一个单元格），主线是 `markitdown` 镜像（表格完整、首行带 `markitdown-mirror` + sha256） | **保留主线**：按 `materials/README` 规则 9，镜像由 `tools/markitdown_sync.py` 生成 |
| `materials/README.md` | 1 | 分支版本更旧：洪祖名 101 件、厉今飞 27 件，且缺 ADR-2026-003 已完成标记 | **保留主线**，并把洪祖名件数更新为 118 |
