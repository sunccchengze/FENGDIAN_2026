## 6. GitHub Release 是什么；本项目怎么处理

GitHub Release 是仓库页面上的一个「版本发布」区域，可以附加供人下载的文件。它不是 Git 提交，也不是自动备份；本项目不需要你学习或操作它。

洪祖名归档继续留在当前仓库，提交历史也不改写。这样最符合「这些提交很重要」的要求。若将来只从最新工作树删除某个文件，旧提交仍能还原它；但 Git 历史中的旧大文件仍会占空间。**这次不做历史重写、不 force-push、不新建替代仓库。**
