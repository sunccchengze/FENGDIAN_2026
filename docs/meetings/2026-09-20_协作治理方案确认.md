# 2026-09-20 · 协作治理与可复现研究工作台方案确认

> 记录人：孙承泽
> 关联决策：[`ADR-2026-001`](../decisions/ADR-2026-001-github-native工作台.md)
> 关联方案：[`docs/14`](../14_协作治理与可复现研究工作台方案.md)

## 1. 会议/确认目标

确认 GitHub 同类项目调研后的技术取舍，并正式进入仓库治理、协作模板、证据链和质量门禁的实施阶段。

## 2. 已确认事实

- 仓库已经是 `Dachuang-SZLS` 唯一仓库；
- `viz/` 是封板科研可视化平台；
- `twin/` 是现役数字孪生平台；
- 项目实际协作者为五人：孙承泽、田铭雨、袁夫达、厉今飞、洪祖名；
- 项目不仅需要代码，也需要研究过程、数据、决策、实验、材料和证据；
- 当前优先解决协作和证据链，不立即引入大型数据/流水线平台。

## 3. 决议

1. 采用 GitHub-native 轻量科研协作工作台；
2. 建立五人职责表和主责/复核机制；
3. `main` 采用 PR 审阅流程，禁止实质修改直接推送；
4. Issue、PR、证据卡、会议纪要和决策记录形成完整链路；
5. MVP 暂不引入 DVC、Kedro、数据库或自研后台；
6. 开始创建治理文档、Issue Forms、PR 模板、证据索引、记录模板和本地仓库检查；
7. 真实 GitHub handle 未核实前，不猜测四位成员的账号，不强行绑定错误的 CODEOWNERS。
