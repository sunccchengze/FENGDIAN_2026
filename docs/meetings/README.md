# 会议与组会记录

> **本文件是「会议纪要」分区明细**，负责纪要规范与会议入口表。
> 全项目时间线主干见 [`../project/TIMELINE.md`](../project/TIMELINE.md)；8 次组会的日期 / 形式 / 地点见 [`../../materials/集体/会议时间线.md`](../../materials/集体/会议时间线.md)。

会议记录的作用不是复述聊天，而是让没有参加会议的人能够知道：发生了什么、决定了什么、谁负责、何时复核。

> ⚠ **当前欠账**：8 次组会中只有 2026-09-19 一次有决议版记录（[`../13`](../13_0919组会决议_三风机改造方案与3x3留档.md)），2026-09-20 一次有本目录正式纪要。**2026-05-17 与 2026-06-01 两次完全无任何记录**，其余各次只有原始材料、尚未按下方模板整理成纪要。

## 每次会议至少记录

- 日期和参加人；
- 会议目标；
- 事实和问题；
- 决议；
- 未决问题；
- 负责人；
- 截止时间或下一次复核时间；
- 关联 Issue、PR、研究记录和材料。

使用 [`../templates/会议纪要模板.md`](../templates/会议纪要模板.md)。

## 会议原始材料的归档约定（2026-10-21 起）

| 层级 | 位置 | 内容 |
|---|---|---|
| 原始材料 | `materials/集体/会议记录/<YYYYMMDD>_<会议主题>/` | 逐字稿（按发言段、带时间码）+ 平台 AI 纪要原文 + README 台账（来源、抓取方式、保留边界、已知偏差） |

| 索引 | 本文件 + [`../../materials/集体/会议时间线.md`](../../materials/集体/会议时间线.md) | 入口与日期／形式／材料对照 |

## 外部会议工具
