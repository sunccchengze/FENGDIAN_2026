# 会议与组会记录

会议记录的作用不是复述聊天，而是让没有参加会议的人能够知道：发生了什么、决定了什么、谁负责、何时复核。

## 每次会议至少记录

- 日期和参加人；
- 会议目标；
- 事实和问题；
- 决议；
- 未决问题；
- 负责人；
- 截止时间或下一次复核时间；
- 关联 Issue、PR、研究记录和材料。

使用 [`../templates/会议纪要模板.md`](../templates/会议纪要模板.md)。

## 外部会议工具

微信群、腾讯文档、HackMD 或在线会议可以用于快速交流，但会后必须把影响项目事实的内容回写仓库。外部链接只能作为补充来源，不能成为唯一的决策记录。
