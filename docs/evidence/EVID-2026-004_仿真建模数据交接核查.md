## 3. 计算和复现

- 全部核查只用标准库与已入库脚本，**未重跑训练**（需 TensorFlow 2.16，作者环境）：

```bash
# 入库前检查（已跑，无阻断项：无绝对路径、无上跳路径、无 0 字节文件、单文件最大 12.0 MiB）
python3 tools/intake_bundle.py --inspect 仿真建模数据交接.zip

# 逐文件校验
cd materials/袁夫达/20261025_仿真建模数据交接 && sha256sum -c SHA256SUMS.txt

# 自洽性独立复算（由 Ueff 反推隐含 Cp·η，见 §4.1）
python3 - <<'PY'
import csv, math, statistics as st
rows = list(csv.DictReader(open("data/cases_wind.csv")))
rho, D = 1.225, 125.88; A = math.pi * (D / 2) ** 2
c = [float(r["P1"]) / (0.5 * rho * A * float(r["Ueff1"]) ** 3) / math.cos(float(r["yaw1"])) ** 1.88
     for r in rows]
print(len(rows), round(min(c), 4), round(st.median(c), 4), round(max(c), 4))
PY
```

## 4. 观测

### 4.1 内部自洽：成立，且可被第三方复算

- 隐含 `Cp·η` 上限 **0.4566**，无越界、无负功率（最小 8.2 kW，最大 4.76 MW），与作者"单机电功率落在 [0, 5 MW]"判据一致。
- 我未复算作者的 15 条判据全部，抽核了三条：功率自洽、功率边界、阵列效率量级（正对来流约 48%）。
  第 15 条"正对来流三机同控制时 P1 ≥ P2 ≥ P3"因数据按 `(ws, wd, ti)` 分块、控制组合交叉，**未逐行复算**（见 §7 问题 3）。
- 与我方 p2 的对照：本数据集在 3D 密排正对来流时阵列效率约 48%，与我们第 2 页「5262 → 2702 kW（−48.6%）」
  属同一量级、方向一致——**这是两条独立路径给出的同一结论**，可作旁证，但两边数字不能互换（工况、几何、风速不同）。

### 4.2 「实测」不成立

- `model/training_report.json`：`"label_source": "simulation"`、`"status": "trained_requires_independent_physical_validation"`。
- `model/config_used.json` 自述："标签源为 FLORIS 解析尾流模型；独立物理校验（Fluent 或实测）仍待补充。"
- 包内 15 个 JSON / 5 个 CSV / 11 张图，**没有一份是实测、外场、SCADA 或 CFD 标签数据**。
- 唯一的非自证物理内容，是作者自己的 Fluent **单机**算例（455,550 单元，学生版上限 512,000），
  作者定位为"流程正确、形态可信，**不能作为定量基准**"——与 EVID-2026-003 对田铭雨那批 CFD 的判定口径一致。

### 4.3 「能跑 PINN」成立，且比我方本轮运行更强的证据在"响应"这一层

| 层 | 袁夫达这批 | 说明 |

## 5. 这些数不能支撑什么

- **不能说"我们有实测数据"**——一句都不行，答辩现场被追问"哪来的实测、几台机、多长时间"会当场垮。
- 不能说"物理校验闭环已成立"；作者自己写的是"**逻辑闭环成立，物理校验闭环尚未成立**"。
- 不能把 50.9 kW（这批 200 轮）与第 7 页的 51.0 / 48.3 / 44.5（我方 120 轮）混着讲，也不可互相替代。
- 不能把"1.02% 额定"单独说成精度——同一份数据里 MAPE 是 22.6%（近停机工况把相对误差拉高），
  作者自己也注明 MAPE 不可作判据。
- 不能把本数据集直接喂给现有优化程序而不做 `P = max(P, 0)`：线性读出层有 445 个负输出（1.8%）。
- 不能外推到 5–12 m/s、`|γ| ≤ 20°`、桨距 0–14°、3D 链式、NREL 5MW 之外。

## 6. 包内两处口径不一致（已记录，不改作者文件）

1. `training_report.json` 写 `Ueff` 取样 "4 radii × 8 azimuths = 32 points"；`docs/dataset_manifest.json` 与
   `README.txt` 都写 8 半径 × 16 方位 = **128 点**。以 128 点为准，前者是旧值。
2. `model/config_used.json` 里有"**实测**该口径误差最低（30.1 kW）"，此处"实测"意为"实际测试过"，
   与"实测数据"同形不同义。对外引用不要照抄。
