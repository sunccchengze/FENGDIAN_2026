# 证据与权威数字索引

本目录记录“结论如何被证明、复现和引用”。它不是新的数据库，也不替代原始研究记录；它提供从材料、README 和答辩数字回到原始证据的导航。

## 证据卡规则

新建证据卡时使用 [`../templates/证据卡模板.md`](../templates/证据卡模板.md)，至少写清：

- 证据编号；
- 研究问题或待验证主张；
- 输入数据和版本；
- 代码 commit；
- 环境和命令；
- 输出文件；
- 结果和不确定性；
- 失败尝试或适用边界；
- 审阅人；
- 被哪些材料或页面引用。

## 数据口径

项目统一使用以下标签：

- **真实**：有明确离线计算、来源或实验记录的结果；
- **代理**：浏览器端或简化模型推算；
- **演示**：用于界面展示的确定性数据，不代表实时场站值；
- **示意**：几何、构图或概念表达，不代表工程测量。

任何材料若把代理、演示或示意数字写成真实结论，必须在 PR 中阻断并要求修正。
