## 文档分层

- `research/`：按轮次记录实验、分析、视觉验证和失败尝试；
- `evidence/`：记录权威数字、证据链和复现入口；
- `decisions/`：记录会改变技术或口径的长期决策；
- `meetings/`：记录会议、分工和后续动作；
- `templates/`：新建记录时使用的模板。

历史文档尽量保留原路径和原始语境。新文档必须写清用途、状态、负责人、日期、来源和后续链接。

## 文件质量标准

重要文档至少要能说明：

1. 它解决什么问题；
2. 它是源文件、派生产物还是历史归档；
3. 当前是否仍然有效；
4. 事实来自哪里；
5. 读者如何验证；
6. 哪些内容不能从它推断出来。

不要在多个 README 中复制同一组容易变化的数字。数字应尽量只有一个权威来源，其它位置只做摘要并链接回来源。
