## 5. 维护规则

1. **完成一项**：划掉（`~~…~~` 或 `[x]`），注明提交 SHA 或日期；**不要删除该行**，否则读者无法知道它曾经存在（沿用 TIMELINE §6 规则 5）。
2. **过期一项**：更新「过期 N 天」的数字，并在 §1 红灯里反映；过期本身不是耻辱，**silent slip 才是**——9.19 §八 原文：「已经过去的申请书里程碑应记录偏差与原因，不补写为完成。」
3. **新增待办**：必须带来源链接（9.19 方案某节 / docs/NN / 群聊某节 / 用户裁定），无来源的待办不进本文件。
