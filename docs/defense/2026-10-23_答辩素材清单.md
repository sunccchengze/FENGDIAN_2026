## 8. 怎么重画

```bash
# 1) 装依赖（沙箱内已装好，换机器时用）
python3 -m venv .venv && .venv/bin/pip install matplotlib numpy pillow

# 2) 22 张答辩图（可只画指定编号）
python3 tools/make_defense_figures.py            # 全部
python3 tools/make_defense_figures.py g01 g11    # 只画这两张

# 3) 2 个动图
python3 tools/make_defense_figures.py gif

# 4) 12 张提取图
python3 tools/extract_defense_assets.py
```

两个脚本都**只读**仓库既有文件：不重跑实验、不改实验目录、不覆盖别人的交付件。
中文字体取自 `~/.fonts/NotoSansCJKsc-Regular.otf`；换机器若无此字体，脚本会退回系统默认字体（中文会变方框，需先装字体）。

改数字只改脚本里的常量，**不要手改 PNG**——改了图就没人知道它对应哪份数据了。
