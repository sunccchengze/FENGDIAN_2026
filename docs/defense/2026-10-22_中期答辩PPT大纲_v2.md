## 0. 这一版按什么原则做

用户 2026-10-22 的四条要求，逐条落成可执行的规矩：

| 要求 | 落成的规矩 | 体现在哪 |
|---|---|---|
| **要按口述速度写稿，把老师想听的都抓到** | 每页先写口播、再倒推屏幕字数。中文按 **4.3 字/秒** 折算，每页「口播字数 ÷ 语速」必须落在预算的 **80%–110%** 之间，脚本自动校验（`deck_v2_content.py` 的 `check()`） | 全片口播 **2944 字 ≈ 11.4 分钟**，预算 **12 分 34 秒** |
| **PPT 当背景，够炫酷、强调数据和方法** | 一页只放一个主张：一个数字、一张图、一张表、三张卡。句子不超过「标题 + 一行副标 + 4 条短语」 | 20 页里有 10 页是纯图/表/数字，没有大段文字 |
| **不放视频，放高清 GIF** | 三个 GIF 全部由仓库真实数据与真实截图生成，**首帧信息完整**（防止对方只播第一帧） | P4 偏航扫掠、P7 七步闭环、P9 三类入口 |
| **不能提 GitHub 仓库** | 全片替换为「**共享资料空间**」「**迭代轮次**」；脚本里写死 12 个禁词，渲染后逐页扫一遍 | 见 §5 替换表 |
| **一气呵成、结尾气势往上推** | 价值四连：国际 → 国家 → 社会 → 下一步 → 谢幕；每页比上一页更硬，最后一句落在「中国的风，由中国人自己的算法驾驭」 | P16–P20 |

## 2. 叙事弧：四段，最后一段一路向上

```
① 值得做        P03               尾流吃掉一半的电（模拟真值）+ 国际天花板 4–20% / 0.4–1.7%
② 真做出来      P04–P10           偏航扫掠 → 逐机贪心 → 五段链路 → 七步闭环 → 十二输入 → 同类入口 → 同权执行器
③ 知道自己在哪  P11–P15           学习有效但没过门槛 → 赢均值输边界 → 三个输掉的场景 → 凭什么信 → 自己划四条线
④ 为什么重要    P16→P17→P18→P19→P20   国际 → 国家 → 社会 → 下一步 → 谢幕
```

**第 ④ 段是这场的关键**：它不是四页并列，是一条**递进链**：

| 步 | 从哪到哪 | 气势靠什么 |
|---|---|---|
| P16 国际 | 世界很大，天花板很低 → **但我们把这条链路做到了可复现** | 谦逊里带锋：先承认别人强，再说「他们的工具链闭环在少数机构手里」 |
| P17 国家 | 装机全球第一 → **下一个问题是「怎么自己验证」** | 从「成绩」转到「缺口」，缺口就是我们的位置 |
| P18 社会 | 电价 / 教育 / 诚信 | 从国家回到每一个人：多发的电、能复用的课、敢报失败 |
| P19 下一步 | **中期不是终点，三件事，每件都有验收标准** | 把「吹」换成「敢承诺」——承诺比形容词有力 |
| P20 谢幕 | **「我们没做出一个漂亮的数字，我们做出了一件可以被检查的东西」** → **「中国的风，应当由中国人自己的算法来驾驭」** | 前一句是自嘲式自信，后一句把整场抬到国家叙事，两句之间隔一道金色细线 |

> **语气纪律**：P16–P19 每页只升一格，不要提前把话说满。P20 是唯一的爆发点——前面越克制，最后一句越响。

## 3. 每页怎么讲（屏上 / 口播 / 手势）

完整逐字稿见 `2026-10-22_中期答辩讲稿_v2.md`。这里只记**口播与屏幕的配合**：

- **P02 四个数字**：手依次点四格，念完第四格停半秒再说「前两个是模型结果，后两个是工程事实」。**这半秒是全场信任的起点。**
- **P03 尾流**：先念场景（5261.9 → 2702.2），再念 48.6%，**然后立刻自己拆台**（「国际上真实风场只有 4–20%，我不拿这个数讲效果」）。
- **P04 GIF**：让图自己动，**不要念图里的数字**，只讲「这条线不是单调的，到 ±30° 反而掉回去」——这是评委没想到的点。
- **P05 柱状**：讲「一台一台让出来的」，手指从低柱划到高柱。
- **P07 GIF**：放完 7 帧约 12 秒，**其间不说话**，让评委看清界面；然后一句「讲完我可以当场再跑一遍」。
- **P13 三卡**：一张卡一句，语速放慢，**念完停两秒**——这是全场唯一一次主动示弱，停顿本身就是说服力。
- **P16–P20**：**逐页提速**，句子越来越短，P20 最后一句之前停一拍。

## 4. 字数纪律（PPT 上到底放多少字）

| 位置 | 上限 | 理由 |
|---|---|---|
| 主标题 | 14 字 | 一页一个主张，超过就说明这页想讲两件事 |
| 副标（kicker） | 30 字 | 副标是结论，不是摘要 |
| 卡片正文 | 每卡 ≤ 40 字 | 评委在 3 秒内要能读完 |
| 表格 | ≤ 6 行 × 4 列 | 超过就拆页或改图 |
| 底部口径条 | ≤ 60 字 | 限定语不能省，但不能长到没人读 |
| **单页总字数** | **≤ 160 字**（除表格页） | 超过 160 字就是「念稿板」，不是背景 |

v2 实测：正文页平均 **≈ 90 字**，最高的 P06（五卡链路）约 150 字。

**为什么用 GIF 不用视频**：视频要等、要缓冲、会把节奏拖散；GIF 循环播放、不占音响、随时可停。三条硬规矩：

1. **首帧必须是信息完整的静帧**——Keynote/PowerPoint 在编辑视图只显示第一帧，首帧空白等于这页空白；
2. **不靠动效传达关键数字**——动效只做「引导视线」，所有数字在首帧就能读到；
3. **GIF 不超过 2 MB**，避免现场加载卡顿（当前最大 2.0 MB）。
