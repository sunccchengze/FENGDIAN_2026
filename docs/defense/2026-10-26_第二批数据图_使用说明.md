# 第二批数据图（2026-10-26）：把已有实验数据翻成能上屏的图

## 0. 为什么有这一批

上一批 25 张图里，流程图、架构图、结论卡占比偏高，真正的「多曲线 / 多子图 / 数据密度」图只有
`g10`、`g11`、`g12`、`g24` 少数几张。评审看惯了顶会的实验章节，会觉得「讲了很多、数据图太少」。

这一批只做一件事：**仓库里已有的 CSV / JSON，本来就能画出 11 张实验图**，不用重跑任何实验、不改任何实验目录。
全部由脚本复算，`python3 tools/make_defense_figures_batch2.py` 一条命令重画。

| 项 | 数值 |
|---|---|
| 新增图 | **12 张**（`g26`–`g37`），16:9，PNG 300 dpi + 矢量 PDF |
| 新增脚本 | `tools/make_defense_figures_batch2.py`（只读数据，`--list` 看图号）+ 公共样式 `tools/figstyle.py` |
| 出图规范 | 按 [figures4papers](https://github.com/ChenLiu-1996/figures4papers) 的科研制图规范，见 `docs/figures-style-guide.md` |
| 图片来源 | Fluent 后处理 CSV 10 份、FLORIS 合成数据集 20,160 行、MADDPG 测试轨迹 30,720 行、PINN 训练报告 1 份 |
| 整包下载 | `docs/defense/figures_batch2_20261026.zip` |

**两条纪律（与第一批相同）**：① 不手改 PNG，改脚本常量重画；② 图上角标与口播必须说同一句话。

## 3. 这两个数必须提前想好怎么答

做图时撞到两处「数据与既有表述不一致」，**不要藏，也不要现在改 PPT 结论**——先按下面的说法讲，等组内确认再改：

### ① 桨距裕度为 0（**2026-10-26 已更正旧结论**）

**旧结论（错）**：早前算「桨距实测 5.88 °/s、超上限 11.8 倍、82% 步越界」。
错在口径：把 `trajectories.csv` 里的 `command_1_1`（**归一化动作**，范围 −1…1）当成了 rad/s 与上限相除；
另外当时按 `case_id` 分组，把 3 次重复的同一 step 行做了相邻差分，凭空造出尖峰。

**更正后的结论**：用物理状态列 `pitch_1`、按 `(case_id, run_id)` 分组逐步差分（每步 1 s），
**三个通道都没有越过配置上限**：偏航最大占上限 39%、转速 27%、**桨距正好 100%（0.50 °/s）**。
桨距不是「超限一个量级」，而是**一直贴着限幅走、裕度为 0**。

- 可以讲：「偏航与转速有明显裕度；**桨距通道的实测最大角速度正好等于上限，裕度为 0**，
  换更长控制周期或更大风况时会最先失效，这是下一阶段要优先补的。」
- 不要讲：「统一执行器约束已全部实现」。
- **不要再讲**：「桨距超上限 11.8 倍」（已被复核推翻）。
- 图：`g34`（整页）与 `fig22`（论文版）均已按新口径重画。

### ② 「−5.8%」是均值，不是每场都赢

18 个常规工况里 **12 胜 6 负**：阵风与慢变几场大幅领先（最多 −171 kW），平稳场末两档与慢变第 3 场落后（最多 +172 kW）。

- 可以讲：「均值 −5.8%，逐场 12/18 更好，差的几场都在图上，主要是目标接近可用出力上限的工况。」
- 不要讲：「全面优于 PI」或「显著优于 PI」。

> 这两条已经写进对应图的「读法」行，图上自证，不用背。

## 4. 怎么重画

```bash
# 一次性装依赖（沙箱/新机器，仓库本身不带 venv）
python3 -m venv .venvs/fig && .venvs/fig/bin/pip install matplotlib numpy

# 全部重画，或只画指定图号
.venvs/fig/bin/python tools/make_defense_figures_batch2.py
.venvs/fig/bin/python tools/make_defense_figures_batch2.py g26 g33 g36
.venvs/fig/bin/python tools/make_defense_figures_batch2.py --list
```

字体：优先 `~/.fonts/NotoSansCJKsc-Regular.otf`（与第一批一致），没有则回退仓库自带的
`viz/site/assets/fonts/songti-sc-black.ttf`（宋体，字重偏重但中文完整）。数字与拉丁字母固定用 DejaVu Sans。
