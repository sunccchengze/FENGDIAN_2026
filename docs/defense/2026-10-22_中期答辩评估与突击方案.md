## 4. 怎么在众多队伍里脱颖而出：三个"记忆点"

### 记忆点 A · 现场跑，不念稿

绝大多数大创中期是 PPT 朗读。你打开浏览器，当场切布局、求解、看功率跳变——**评委的眼睛会亮**。
- 准备：离线包（`npm run build` 后的 dist + 本地起服务），**不依赖校园网**；
- 兜底：`docs/research/img/r44_demo_step{1..7}.png` 七张截图做静态备份，网断了不慌。

### 记忆点 B · 把"负结果"讲成方法论的证据

> 建议原话：「我们的 MADDPG 平均比 PI 好 5.8%，但有一条训练流输给 PI，慢变和低风压力场都输。**我们没有把这 5.8% 写成'算法优越'**，而是把失败场景单独列出来，当作下一轮的靶子。」

这句话的价值**远大于**十个漂亮数字——因为它证明你们懂"什么算证据"。评委见过太多"我们提升了 30%"却说不清怎么算的组。

### 记忆点 C · 每个数字都能点回去

现场如果有人问"这个 449.72 哪来的"，你**当场打开仓库**：
`optimization_control/experiments/20261022_random_wind_training/` → `metrics.csv` → 30,720 行轨迹复算 → 差值 0 W。

> 这一手的杀伤力在于：**别人无法验证，你们可以。** 这就是"顶天"和"吹牛"的分界线。
