# ADR-2026-004 · 仓库转公开 / 整包外发的前置清单（隐私与版权）

- **状态**：**提议（待团队批准）**
- **提出**：2026-10-22 全仓审计（AUD-14）
- **背景**：本仓目前 private，隐私与版权风险靠私有属性兜底。结题、软著、展示
  都可能要求转公开或整包外发；以下暴露面会随一次可见性切换**同时**公开，
  必须先逐项裁定，不得先公开再补救。

## 暴露面清单（2026-10-22 实测）

| 类别 | 位置 | 现口径 | 转公开前须裁定 |
|---|---|---|---|
| 申请书终版（含成员联系方式） | `materials/`（README §7 记用户裁定按原样保留） | 私有仓内保留 | 脱敏副本或移出；联系方式不得随公开仓外泄 |

## 建议流程

1. 先在本 ADR 逐项落裁定（保留公开 / 脱敏 / 移到 Release 或仓外 / 取得授权）；
2. 用新分支做一次「公开面演练」：按裁定物化后跑 `python3 ci/repo_quality.py`
   与全文敏感词复查（手机号、邮箱、学号模式）；
3. 历史里已提交过的内容无法靠删文件消除——真要公开且含不可公开历史时，
   优先以**新仓单根提交**或 Release 材料包形式对外，而不是翻转本仓可见性；
4. 完成后再切换可见性或外发，并把裁定记录回本 ADR。

> 本 ADR 在批准前不改变任何现状：所有材料按用户既有裁定**原样保留**，
> 本文件只把「公开那一步」变成有清单的显式动作。
