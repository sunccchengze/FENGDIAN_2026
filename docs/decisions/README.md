本目录只收录会影响技术路线、数据口径、仓库边界或长期协作方式的决策。

## 记录规则

1. 先用 GitHub Issue 或 Discussion 描述问题和候选方案；
2. 达成共识后，用 [`../templates/决策记录模板.md`](../templates/决策记录模板.md) 形成仓库内记录；
3. 通过 PR 审阅和合并；
4. 后续变更不得悄悄覆盖原结论，应写明 supersede 关系；
5. 会议纪要只记录讨论过程，最终技术裁决应在这里或对应正式文档中落地。
