# 袖珍轨道站 · SCZ Pocket Orbit

> 给承泽 · 2026-09-15 07:00 的晨间惊喜

把你散在 17 个公开仓库、10 条 arena 分支、21 个一次性单页里的所有痕迹，捏进一座 1240px 的轨道站。

- **硬核侧**：FLORIS 4.6.6 GCH 口径的 3×3 软体风场，9 颗涡轮偏航可捏，尾流随 yaw 偏转，功率用真实 `cases_array.csv` 双线性代理实时推算，诚实标注 E2。
- **软糯侧**：复用 nieniexiaoying 的弹簧物理与 WebAudio 合成，4 种手感（捏/拉/挠/抛），奶油底 + 冰青 #5fd6ff。
- **个人侧**：6 个月箴言倒计时、238 技能轨道、13 条启发式+4类风险灯、打脸链路实验账本、来自 2027-03-15 未来的那封信。

**零构建、零后端、纯静态**：直接 `python -m http.server` 即可打开，所有状态存 localStorage。

```
python3 -m http.server 8000 --bind 0.0.0.0 --directory pocket-orbit
# 打开 http://localhost:8000
```

**诚实口径**：风场功率为代理预测，非实测；软体形变为示意，非 CFD 等值面；时间胶囊为基于你自述与蒸馏档案的拟构，非预言。
