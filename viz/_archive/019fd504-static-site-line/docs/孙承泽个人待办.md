## 1. 核心目标（来自 PPT，一个月后能演示）

> 输入风况与偏航角 → 预测尾流与功率 → 搜索较优偏航角 → 可视化展示结果。要求：✅可运行演示 ✅最小闭环。

- **最小闭环设定（第一版）**：两台串列风机；固定{风机型号、间距、风向、湍流强度、桨距角、转速}，**只变{来流风速 U∞、上游偏航角 γ₁}**。
  → 我的 `site/` 正是这个设定（双机、U∞ 选择器、γ₁ 扫描），与 PPT 完全对齐。
- **优化方法（第一版）**：网格搜索，枚举 γ₁∈[−30°,30°]，调代理模型预测 P₁/P₂，选 argmax(P₁+P₂) 并可视化；**不急上强化学习**。
  → 我的 `find_yaw_for_target` 就是插值暴力搜索（网格搜索思路），方向一致；开学后接洪祖名的 PPO/MADDPG。
