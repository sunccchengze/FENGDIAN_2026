## 四、厉今飞神经网络选型理由（正式答复李良星老师）

- **特征 6 维**：风向周期 → sin/cos + 二阶谐波。
- **Swish 隐藏层**：良好非线性与梯度传播。
- **Sigmoid 输出层**：单机 0–5MW 归一化到 0–1，从结构限制物理边界。
- **求和得全场**：保证功率守恒。

## 五、假期前 PPT（组长厉今飞会议）消化 —— 直接指导孙承泽可视化

- **核心目标（一个月后能演示）**：输入风况+偏航角 → 预测尾流与功率 → 搜索较优偏航角 → 可视化展示。要求 ✅可运行演示 ✅最小闭环。
- **完整链路**：CFD高保真 → POD降阶 → AI代理模型 → 优化控制(网格搜索/RL) → 可视化验证演示。
- **最小闭环（第一版）**：两台串列；固定{型号、间距、风向、TI、桨距、转速}，**只变{U∞, γ₁}**。—— 与 `site/` 设定一致。
- **优化方法（第一版）**：网格搜索 γ₁∈[−30°,30°]，调代理模型预测 P₁/P₂，选 argmax(P₁+P₂)；**不急上 RL**；闭环跑通后再上 PPO/MADDPG/粒子群/贝叶斯。
- **统一数据接口（PPT 规范）**：
  - `cases.csv` 最小字段：`case_id, U_inf, yaw_1, yaw_2, pitch, rpm, power_1, power_2`
  - `fields/case_XXXX.npz`：统一网格 128×64，存 x,y,u,v 或 velocity
  - **给可视化的数据接口**：`wind_speed, original_yaw, recommended_yaw, power_before, power_after, wake_field`
  - → 我的 `optimizer_result.json` 已覆盖前 5 项；`wake_field` 未来接田的 CFD npz。
- **五周作战表**：第1周=冻结需求+假数据闭环（**我今日站点即此交付**）；第2周小规模CFD；第3周真实代理模型(POD/SVD)；第4周优化与展示集成；第5周验证总结。
- **分工（可视化）**：学习重点=云图、布局、参数输入、前后对比、接口读取；本周交付=读取 JSON/NPZ 的演示界面（已完成）。
- **学习顺序原则**：先能跑、再准确、最后再高级。
- **评价指标**：系统性能含"单次代理模型推理时间、界面响应时间"——纯静态站零后端、毫秒级、CDN 快，正是相对 Streamlit 的优势点。
