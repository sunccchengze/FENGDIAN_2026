## 2. 任务详情

### T1：Cp 解析公式环境 + 单机 PPO 功率跟踪 ✅

- **目标**：不依赖队友，打通「环境 → PPO → 评估 → 记录」RL 工具链。
- **内容**：
  1. `environments/simplified_turbine_env.py`：Cp 经验公式环境（状态 `[P, ω, β, U, P_target]`，动作 `[Δβ, Δω]`，一阶转速动力学，奖励 = 跟踪误差 + 动作平滑）
  2. cleanrl PPO 单文件训练脚本（seed=42）
  3. 单机比例控制基准与 PPO 评估脚本
  4. tensorboard + 实验记录（`experiments/YYYYMMDD_.../`）
- **产出**：环境代码 + 训练脚本 + 评估曲线 + 实验记录
- **历史结果口径**：2026-08-08 目录中的 RMSE 和图片保留用于追溯；经 T1-R 发现旧 P 基准控制方向错误，旧“PPO 优于 P 基准约 34 倍”结论作废。
- **依赖**：无（项目 `.venv` 已就绪；PPO 为基于 cleanrl 改造的本地单文件实现，不依赖 `cleanrl` 包）
- **commit**：见 git 记录（train.py / eval.py / simplified_turbine_env.py）
- **实验结果**：`experiments/20260808_ppo_single_turbine/`
- **教训**：① 目标必须物理可达（8m/s 最大 ~1.9MW）；② 训练/评估观测归一化必须一致（wrapper vs 内建）

### T1-R：单机 PPO 记录与 P 基准修复 ✅

- **目标**：让 T1 工具链可以生成语义正确、可复查的新实验结果。
- **修复**：正确记录回合回报；校验 `PController` 方向；统一 reset 目标与首步目标；把 200 步定义为合成任务终点并使用 SAME_STEP 自动重置；按动作上限归一化惩罚；新 PPO 使用 tanh 压缩高斯并按真实边界映射；历史评估显式选择策略格式。
- **验证口径**：轻量 smoke 只证明流程可运行，不作为正式性能结论；正式比较必须重新训练、使用多个随机种子并报告置信区间。
- **历史保护**：不重写旧 RMSE、旧图片或旧 `metrics.csv`，只明确其限制。

### T2：PINN—优化接口与含控制参数数据需求 🔄

- **目标**：先冻结 PINN—优化闭环接口，再据此向仿真组提出可训练、可验收的数据需求，支撑正式 RL。
