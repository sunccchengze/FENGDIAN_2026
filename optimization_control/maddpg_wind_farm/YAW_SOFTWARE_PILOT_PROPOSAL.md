# 偏航逐通道接管与小预算软件试验提案（2026-11-05）

采用正式选择锁的 C selected 三流作为固定父，分别为 0／0／4096 步。前两流保留原桨距能力及零 speed 修正，第三流保留已选的转速修正。本轮新独立测试只用来评估这些固定身份。偏航试验仍待结构和预算审阅。[正式选择锁](../experiments/20261104_forecast_speed_formal/selection.json)

## 模型限制与必须核对的接口

已有扫描中，yaw 共同扰动的代理功率响应绝对值中位数为 .73 kW，合成标签为 7.29 kW。在标签响应至少 1 kW 的记录中，方向不一致占 38.65%，逐机扰动占 44.04%。当前结果支持把试验限定为代理内软件联调。局部响应弱仍可以检验动作接通、恢复和训练流程，真实物理增益需要独立依据。[已有同点响应扫描](ANCHOR_CLOSEOUT_RESULTS.md)

现有源码从命令失配参考和当秒来流构造机舱参考，以最短圆周差驱动原执行器。PINN 输入失配由实际机舱朝向减当步来流并 wrap 得到。适配器使用 SI 的 rad、rad/s 以及从 +x 逆时针的 flow-to 风向，将三机物理量按团队顺序重排并对角度 wrap。源码审查未定位到已知的单位或映射错误。工程必须用已知输入逐项验证以下合同，出现错误先修映射，再解释响应或训练表现。

| 核对 | 预定样例 |
|---|---|
| 单位与通道顺序 | 输入独立三机标记，逐项核对进入团队模型的 yaw/pitch/speed 顺序与 rad/rad/s 量纲 |
| 来流与机舱参考 | 固定朝向、两侧变化来流，验证失配为 heading 减来流且经过 wrap |
| 圆周与限速 | 穿越 0/2π、正负 1°，验证最短转向和 .005 rad/s 约束 |
| 保持与奖励 | 8 秒保持修正，逐秒按真实总命令和原奖励计算，终止按实际 m 折扣 |
| 公共物理域 | 使用原执行器、相同位置和速率边界、PINN 域检查。失败标注 case 和输入字段 |

## 工程阶段

沿用转速版的决策边界回放和私有版本加载。C 父的原桨距在线映射每秒按实际观测反馈，C 的 speed head 每 8 秒按自身因果历史选择。新增零末层 yaw head 使用 15+36 维输入，集中 Critic 使用联合观测 45、共享预测 36 和实际三机 yaw 修正 3。首版在每个 8 秒边界选择 yaw 修正，单机范围 ±1°。物理修正叠加在原参考失配上，由原环境转换成机舱参考。执行器实际朝向和来流决定送入模型的失配角。C 的桨距和转速映射及目标来源冻结，反馈仍响应闭环观测。

工程用旧验证集每族预选一风。三父各以直接父和零 yaw 接管完成 3 风，2322 行含 reset。当前与目标零头同时检查，闭环动作、实际量和功率/RMSE 容差沿用 2e-6、1e-6 和 1W。另用一流 mock 做 4 个完整回合及保存前一次更新，连续与新进程各跑下一回合和一次更新，774 行含 reset、3 次工程联合更新。合计计划 3096 行，上限 4096。只在完整 128 步边界恢复。记录独立回放、Adam、计数、样本索引、forecast 和执行器轨迹。工程状态另标用途。

## 获批后的小预算学习阶段

两臂各三流、各 2048 个物理步，总计 12288。共同 seed42 派生训练风和目标，训练命名空间预留从 70000000 开始，释放前查实际占用。训练风与已经释放的 69000000 测试独立。固定旧六条 validation 用于筛查和选模。选模点为 0/1024/2048，严格均值改善，平手保留早期。相同环境、1 秒物理步、8 秒决策、gamma=.99、额外 TD 展开一个宏样本，原逐秒奖励和物理约束。两臂同一新增预算下在第 512 物理步起每两个闭合宏样本更新，共 97 次/流。

两臂沿用 head LR=1e-4、Critic LR=.001、tau=.01、batch=64、宏容量 4096 和梯度裁剪 1。探索只在决策边界，归一化 z 噪声 std=.15，按新增物理步从 1 线性衰减至 .2。使用配对的新探索随机流，S 的继承回放抽样状态按来源记录。评估噪声为零。

- Y 在冻结 C 上只训练 ±1° yaw 修正，独立空宏回放和新 Adam，权限为桨距反馈＋转速＋偏航。
- S 按同预算续训原 C speed head，yaw 仍由原调度。C2 继承选中训练状态，C0/C1 重建已锁初态。对比解释为完整训练方案，分别披露回放来源和可训练模块。
- Y 的关闭 yaw 回放与固定 C 对照用于判断新增通道的作用。公共 P／PI 用于完整方案比较。未来独立测试按用户三族分别平均优于 PI 的主指标，逐流、最差、压力、原 400/500、selected=initial 和 final 退化另列。
