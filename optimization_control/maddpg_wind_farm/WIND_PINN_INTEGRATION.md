# 十二输入 PINN 联调与分阶段学习（2026-10-22）

本轮任务经用户确认：接入 `pinn/2026_1021`，以软件全流程可运行为目标；没有物理数据，所有合成拟合、控制误差均不得表述为真实精度。队友目录只读，原冻结主干不变。

## 文件与产物约定

- `environments/wind_pinn_backend.py`：十二输入 SI 桥接、模型/报告核对、圆周风向和有效域检查。
- `maddpg_wind_farm/wind_pinn_demo.py`：合成数据、仅新增参数拟合、响应检查、闭环和回放。
- `maddpg_wind_farm/wind_pinn_curriculum.py`：有固定预算的逐级学习及冻结独立评估。
- `configs/wind_pinn_*.yaml`：主种子 42、模型和控制配置、阶段预算及晋级规则。
- `experiments/20261022_wind_pinn_*`：沿用项目实验约定；保留 config.yaml、metrics.csv、summary.txt，数据/模型/轨迹不入 Git。失败产物保留，不覆盖或自动清理。

## 契约及演示假设

优化外部顺序 `[U,theta,TI,gamma123,beta123,omega123]`；桥接到队友顺序 `[U,theta,TI,gamma1,beta1,omega1,...]`。角度 rad，转速 rad/s，输出 `[P123,Ueff123]` 使用 W、m/s。风向为吹向、+x 零度、逆时针正；图内完成 sin/cos 和机位旋转，外部不重复。机舱执行器产生 heading，实际 gamma=wrap(heading-theta)。

固定三机机位沿用演示 `[0,0,90],[378,0,90],[756,0,90]` m；每机额定 5 MW，均非队友标定。模型域 U=[7.5,10.5] m/s、theta=[-0.15,0.15] rad（圆周等价）、TI=[0.02,0.15]；gamma=[-0.4,0.4]、beta=[0,0.22]、omega=[0.6,1.267]。yaw 目标更窄，给风向跟踪滞后保留余量。

合成标签使用明确标记的布局相关三机测试公式，包含 U、theta、TI 和九个实际控制量的响应。它不是 CFD/PINN 物理真值。训练实际队友网络副本，仅新增 27,106 个参数可变；统计只用训练集，冻结主干摘要前后及重载一致。独立验证/测试合成样本不参与拟合。

## 执行和验收顺序

1. 完成新桥接及旧版搬家兼容，检查列序、单位、周期、几何、归一化和非法输出拒绝。
2. 4096/512/512 个独立训练/验证/测试样本；上限 120 epochs，验证早停 patience=16，仅按验证选模。若探针发现非法输出或控制响应错误，保留失败结果，先处理模型层问题。
3. 新网络上短 MADDPG 2048 步（功能验收），固定风和 stationary/ramp/gust 入口统一回放，和 fixed/P/PI 共享初态、目标、轨迹、动作映射及执行器。核对机舱速率、失配角、功率求和、重载和完整回放。
4. 固定 U=9、theta=0、TI=0.1，扫描仅桨距可达范围，按区间 25%/50%/75% 选择三个目标。每目标最多 16,384 步；只用验证选模，包括初始策略。
5. 单目标全部通过才训练多目标仅桨距（最多 32,768 步），再分别加入转速、偏航（各最多 16,384 步）。每个任务使用主种子 42 派生的单训练流，属于功能/能力诊断，不做多种子优势声明。失败停止晋级，后续通道仍有第 3 步功能检查覆盖。
6. 学习通过要求：验证选中策略优于初始，最差末 32 步 RMSE <=100 kW；多目标还需端点响应比例 >=0.8。另列最终/最佳验证比，超过 1.25 标为后期退化；不把选中策略等同稳定终点。测试仅在所有阶段和对照参数冻结后开启。

同权限对照和完整 P/PI 方案分别标记。训练、验证和测试入口用生成器的独立 split/episode，评估各方法回放同一文件。后续真实数据/物理精度验收另行开展。

```powershell
# 新实验：数据、拟合、模型响应检查、2048 步混合来流短训练与统一评估
.venv\Scripts\python.exe -B -X utf8 -m optimization_control.maddpg_wind_farm.wind_pinn_demo all --output optimization_control/experiments/20261022_wind_pinn_integration

# 新进程加载模型和策略，逐行核对原评估；目标目录必须不存在
.venv\Scripts\python.exe -B -X utf8 -m optimization_control.maddpg_wind_farm.wind_pinn_demo replay --output optimization_control/experiments/20261022_wind_pinn_integration --replay-output optimization_control/experiments/20261022_wind_pinn_replay

# 旧九输入交付搬家后的冻结策略回放
.venv\Scripts\python.exe -B -X utf8 -m optimization_control.maddpg_wind_farm.handoff_replay --output optimization_control/experiments/20261022_legacy_pinn_replay
```

若日期目录已存在，完整新实验使用新的输出名称；阶段入口 `prepare/fit/control` 可分别运行，不能覆盖已有阶段。固定风学习中断可使用同一命令附加 `--resume`，仅在身份匹配、独立测试未开启时恢复。

合成模型默认配置为 `configs/wind_pinn_demo.yaml`；阶段协议为 `configs/wind_pinn_curriculum.yaml`。更换第一条的输出时，也需在新协议中改 `source_experiment`，以明确绑定模型版本。新进程回放只在内存中重定位模型/脚本路径，检查点和摘要不改写。

## 分阶段学习结果与停止原因

三份独立单目标策略各训练 16,384 步，共 49,152 步。验证初始桨距 0.04 rad；冻结策略与对照参数后，独立测试改为 0.025/0.055 rad。单目标测试仍使用对应固定目标，不能据此宣称一份策略学会多目标。

|---|---:|---:|---:|---:|---|
| 2.766 | 1361.73 | 12288 | 18.14 | 1.008 | 通过 |
| 3.452 | 675.65 | 14336 | 1.69 | 1.004 | 通过 |
| 4.138 | 10.39 | 0 | 10.41 | 2.306 | 未通过：未优于初始且终点退化 |

第三组的选中步数为 0，明确是初始策略。其训练终点验证全回合 RMSE=23.96 kW，不能报告为学会高目标。低/中目标选中策略分别为 209.88/65.32 kW 全回合 RMSE，包含执行器调整初期的误差，与末段精度区分。

按预定“单目标全部通过才晋级”的规则，在单目标层停止；多目标、加入转速和加入偏航的学习阶段本轮未启动。yaw/pitch/转速的功能接通已由此前三通道短训练与统一回放覆盖。

本轮证据表明：新版接口和控制链路可用，低/中固定目标在当前合成网络上可学习；高目标起点已经很好，继续学习没有得到更优策略且终点退化。它不等价于“高目标不可达”，也未证明某一项算法机制是唯一原因。下一轮若研究学习能力，应在训练前固定初始功率与目标的最小间距，或设计明确的初始扰动，再独立诊断高目标退化；不能根据本轮测试修改原结果。
