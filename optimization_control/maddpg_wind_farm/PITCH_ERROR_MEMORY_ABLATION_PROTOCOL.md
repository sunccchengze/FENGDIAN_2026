# 桨距误差记忆的闭环消融与参数漂移审计

2026-11-05。承接 `21d7421`，仅诊断误差记忆。新建实验目录 `optimization_control/experiments/20261105_pitch_memory_ablation/`。冻结三流原 n8 父与正式 `memory`／`zero` 的 initial、selected、final，记录权重和轨迹来源的 SHA256。场景固定为 36 个已知开发场和 18 个既有 validation 场。主组为已知 `train_episode_8` 两个初态 × 三流。全组和慢变都报告。测试及压力数据不作为输入。P／PI、模型、执行器、风向跟踪和转速曲线沿用原设定。

先执行离线审计，代理输入为零。分别记录三机 Actor、Critic 及目标网的新增权重范数、原参数相对初始和选中点的漂移。分析 initial／selected／final 回放当前 I，以及三流两臂新训练转移和已有 validation 正常轨迹。按风况、目标、初始桨距分层，记录 I 分布、正负触边比例及与当步有符号误差的关联。回放新增段按绝对序号匹配训练风况。继承段可由观测精确读取目标，风况无身份时单独标记。既有评估时序未保存完整观测，离线同状态探针用三流 memory 训练转移中每个完整回合的决策步 0、8、…、120；每个状态保留真实 I 与记录动作。父、恒零和两个记忆角色均在共同状态上比较。记忆组分别令输入为真实 I 和 0，输出三机桨距差与真实 I 处局部导数。Critic 固定同一记录联合动作，比较两种输入下各 Critic 的 Q 与本机桨距方向动作梯度。旧网络差异由各角色统一读取 0 的动作及梯度比较，Q 尺度只作诊断。

冻结案例、引用身份、离线统计规则和诊断脚本后，只运行六个 memory selected／final 的读 0 闭环。使用同权重，每一步输入本反事实闭环的实际观测与常数 0。内部仍根据自身当前误差和已裁剪桨距命令递推真实 I，单独记录。每槽位 128 步加 1 行 reset。全部 324 回合，计划 41,796 行，统一硬上限 50,000 行，含任何预检与失败尝试。复用已核验的正常、恒零、父、P 和 PI 完整轨迹，核对案例身份、完整 RMSE、风速与偏航。validation 父使用同动作的 memory initial 保存轨迹，需核对初始权重与原父一致及零支路权重。第一个闭环先核对第 0 步命令与正常轨迹一致，作为正式 324 回合的一部分。保留每个完整反事实时序及异常账本。全部产物上限 128 MiB，模型权重和回放只读。优化器更新、新独立测试均为 0。

逐完整回合报告 RMSE、平均有符号误差、bias²、方差、实际桨距运动与速率／边界比例。分别统计正常−读 0、读 0−恒零、读 0−父，以及记忆正常和读 0 的 selected→final。按集合、流、风况、目标及初态保留配对差，报告严格弱 PI 计数。正常−读 0 描述部署时这条通路在本组场景的闭环影响。其余差异包含训练路径、网络参数和状态分布改变，Q 或梯度只是网络内证据。最终报告仅依据上述结果提出一项后续干预，或说明尚无法区分根因。本轮交付不改变默认策略。
