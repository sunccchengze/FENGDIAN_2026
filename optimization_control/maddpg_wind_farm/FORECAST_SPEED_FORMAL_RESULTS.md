## 实现、数据与复现

A 继承原父训练状态和逐秒回放，新增 3841 次联合更新／流。B／C 冻结三原父在线映射，配对新 head、Critic、空宏回放和空 Adam，新增 481 次／流。B 的预测块为零，C 使用原冻结 ridge。宏动作每 8 秒选择一次，父桨距及参考调度继续每秒反馈。回报从真实逐秒环境奖励折扣展开。正式加载器通过用途标记区分工程状态。工程实现的旧源摘要从工程提交的原始 Git blob 复核，本轮源文件差异为可继承的用途标记。

三工作树扫描 8641 个 JSON，未发现 192 条训练、6 条验证及 18 个预留未来测试身份的冲突。三臂同流共享完全相同的训练风、初始桨距和目标。锁定风库的 float64 数据由环境按 float32 接入，轨迹复核使用这一入口精度。已知压力用固定 7.6m/s、4.4MW、.04rad，按单独分组报告。[训练与验证配置](../experiments/20261104_forecast_speed_formal/config.yaml) · [命名空间核查](../experiments/20261104_forecast_speed_formal/namespace_check.json)

run 0 三臂都在 2048 步完整保存、退出后由新 PID 加载，从 episode 67000016 的第 2049 步继续。三个进程恢复均按已锁身份检查计数和完整状态，后续 episode 顺序和查询凭据保持连续。8192 步结束后共保留 36 份完整状态，另存轻量推理快照。结果角色引用既有路径及 SHA。
