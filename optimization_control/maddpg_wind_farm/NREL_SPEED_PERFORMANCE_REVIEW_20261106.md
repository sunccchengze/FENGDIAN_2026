**统计口径。** 定义第i回合第t步误差 `e_it=(P_farm_it−P_target_i)/1000`，单位kW；正值表示过发。每回合目标固定，使用总体方差ddof=0：

`b_i=mean_t(e_it)`；`v_i=mean_t((e_it−b_i)^2)`；`MSE_i=b_i^2+v_i`；`RMSE_i=sqrt(MSE_i)`。

聚合前先完成每回合分解，再对回合等权：`E[MSE_i]=E[b_i^2]+E[v_i]`。Y总体对18回合等权，各族对三流×两场等权；P／PI总体各六回合等权，各族各两场等权。主报告的“平均RMSE”是 `E[RMSE_i]`，平方分解适用的是 `E[MSE_i]`。`sqrt(E[MSE_i])`为本表的pooled RMSE；因各回合同为128步，它等于把相应误差样本合并后算RMSE。不得用 `E[RMSE_i]^2` 代替 `E[MSE_i]`，也不得用 `E[b_i]^2` 代替 `E[b_i^2]`。若合并后先减总均值，方差还包含回合均值间的离散程度：`E[b_i^2]=E[b_i]^2+Var_i(b_i)`。

**固定目标跟踪与最大Cp。** 本任务损失是 `(P−P_target)^2`。在已过发的局部状态，若提高omega使当前代理的P继续增加，跟踪平方误差就可能增大；降低欠发则可能使它减小。用kW表示P时，局部导数为 `d(e²)/domega=2e*dP/domega`，符号同时依赖功率误差和功率敏感性。最大Cp对应的转速参考没有直接优化这个固定目标损失。7.55在本轮是基础参考的设计值；实际TSR还受修正、执行器和变化中的Ueff影响。冻结模型内RMSE变差不构成NREL理论失败或立即回滚的依据，也不证明需要重训。

[当前软件标签函数（交付范围说明）](../../materials/洪祖名/20261106_optimization_final/README.md)使用入口风形成 `clip(U_inlet/11.4*1.267,.6,1.267)`，其extraction还通过上游尾流影响下游Ueff和功率。新控制基础参考使用各机Ueff。两者假设不同，可以作为待核查的模型内机制，标签函数仍只是未标定的软件假设，不能作真实风机、真实Cp或代理误差的真值。

**有界静态诊断设计审查。** 主侧已授权：原六条validation×旧／新×Y2／PI×t=32／96，共48个预定锚点。每个锚点固定入口U／theta／TI和实际pitch／gamma，改变omega后重新预测全部三机P与Ueff；实际重放1行、旧／新联合参考2行、逐机7点共21行、各机±.01局部6行，最多30行／点，预计≤1440行，硬限2048模型输入行／32MiB，环境步、训练和新风均0。现有设计无实质阻断，支持按原授权继续；本审查不要求先完成另一轮设计验收。

需在记录中明确下列含义，均属原设计的执行细节：

1. 实际重放使用保存行的入口条件、物理pitch、实际失配gamma和实际omega，按原输入次序、float32处理与冻结预处理重建12维输入。先报告与保存P／Ueff的重放残差及采用的数值容差；若不一致，后续差异先按来源／数值问题处理，不能直接解释为转速响应。gamma取保存 `applied` 的失配列，不能误用机舱绝对heading列。
2. 一次性用保存Ueff计算旧／新三个omega联合参考，记录Ueff取行与来源。历史t行的执行命令使用t−1响应Ueff；若用t行Ueff构造静态参考，则称为锚点的一次性探针，不称为t行历史命令重放。更换omega后Ueff是模型输出，随全部omega重新预测；不将它当固定外因，也不循环代入寻找所谓自洽最优。
3. 逐机7点和±.01探针需写明其他两机omega固定在什么向量、7点范围及局部差分分母。保持原预定范围与原模型域检查。局部点如遇边界裁剪、单边或重复，按实际采样值与行数记录，不把不等距探针除以固定.02。记录每次实际输入行，重复点可复用，但不得隐去失败／重试成本。
4. 每条探针保留三机P、Ueff和农场总P；结合该锚点目标计算有符号误差和平方跟踪误差。单机omega既可能改变自身功率，也可能经代理耦合改变其他机输出，因此农场总功率敏感性与单机功率敏感性应分别解释。软件标签响应可作假设对照，与代理输出分列。
5. 旧／新同case同t的锚点已经来自不同闭环，实际pitch、gamma和omega可能不同。静态对照能隔离每个锚点内部“只改omega”的代理响应；直接比较两套锚点输出仍含各自状态差异，不能称闭环唯一因果解释。两个时刻、Y2和PI也不代表全部128步、三流和P。

诊断能够回答：当前代理在这些固定输入附近的局部功率敏感性方向／量级，联合参考更换是否在静态状态下扩大或缩小固定目标误差，Ueff耦合是否明显，以及响应是否与软件标签假设同向。它能为后续是否值得提出有预算的重训提供证据。

诊断不能回答：时间响应与误差方差增长的完整来源、积分和执行器滞后的动态贡献、新策略能否通过训练恢复精度、真实风机Cp最优，或连续三维转速及九维控制的全局最优。逐机7点的最大输出只是其他量固定时有限采样中的最大值，不称真实最佳；最大功率也不等于最小跟踪误差。本轮保持NREL新曲线，不由这次迁移结果追加候选、改曲线或启动训练。

from pathlib import Path
import json
import numpy as np
p = Path('./optimization_control/experiments/20261106_nrel_speed_transfer')
l = json.loads((p/'lock.json').read_text())
c = json.loads((p/'complete.json').read_text())

for version, refs in [('legacy', l['old_evaluations']), ('nrel', {x['controller']: x['eval'] for x in c['results']})]:
    for name, ref in refs.items():
        metrics = json.loads(Path(ref['metrics']['path']).read_text())
        with np.load(ref['trace']['path'], allow_pickle=False) as z:
            traces = z['trace']
        for metric, t in zip(metrics, traces, strict=True):
            e = (t[1:, 2] - t[1:, 1])/1000
            b = float(e.mean()); v = float(e.var(ddof=0)); m = float(np.mean(e*e))

            assert abs(m**.5-metric['rmse_w']/1000) < 1e-9

assert len(rows) == 60
for version in ('legacy', 'nrel'):
