# C selected 偏航工程接管协议（2026-11-05）

本轮按主对话转达的用户批准完成偏航工程实现与验证。起点为正式 C selected 三流 0／0／4096，父的桨距和转速反馈映射冻结。协议在模型查询和工程更新前冻结。既有实验、PINN 和共享状态入口按 SHA 保护。产物沿用 `experiments/YYYYMMDD_简短描述/`，本轮为 `20261105_yaw_engineering`。保留全部失败记录，文件独占创建，重试先重新核对累计预算。

## 接口和时间

父桨距每秒使用当步真实观测。父转速每 8 秒使用同一观测和因果前缀决定 .1 rad/s 有界修正。新增三机 yaw head 每 8 秒决定 ±1° 修正，叠加到父失配参考，再由原环境换成机舱参考，原执行器限制共用。

边界顺序为先读取 t 的观测和历史，共同计算父 speed 与 yaw，再组合动作、执行一次、追加 t+1 来流。两个决策时钟分别记录，禁止额外推进父 Episode 或重复追加历史。父 current 映射用于真实反馈和新 yaw Critic 的固定背景。新 yaw target 单独 soft update，父 delayed 网络仍留在父来源文件，父 current 权重保持冻结。

Yaw head 输入 51 维，Critic 输入 84 维。三 head 使用独立 seed42 派生种子、零末层、独立空 Adam、私有宏回放和版本格式。回放 z 是实际经过裁剪的 yaw 修正，逐秒奖励使用实际三通道总命令，宏 return 按实际 m 折扣。terminal 禁止 bootstrap。重用已验证宏优化逻辑，私有 yaw 状态与 speed 状态互相拒绝。

## 预定验收

- 旧 validation 固定索引 0／2／4，每族一条。三父均执行直接 C 与零 yaw 两种完整 128 步闭环。online／target 零 yaw 在每步均检查。动作容差 2e-6，实际物理量 1e-6，功率和 RMSE 1 W。保持序列、历史摘要和回报逐项核对。
- 使用三机不同 SI 标记独立核对进入团队模型的 yaw／pitch／speed 顺序。纯算术角度跨 0／2π 和正负 1°，核对 shortest-angle 与 .005 rad/s。算术域外值仅作角度验证。
- C2 在同一旧 stationary validation 上分别执行 +1°／−1° 工程序列，核对实际 heading、进入 PINN 的 gamma、原限速和逐秒总动作奖励。记录响应，禁止据此选模。
- mock 三机通道、父 speed 零／非零均覆盖。4 个完整回合收集后更新一次，512 步落盘。连续与新进程下一完整回合和一次更新结果按字段、dtype、形状比较，包含网络、目标、Adam、回放、样本索引、RNG、两个时钟、held speed、history、yaw pending、执行器和轨迹。
- mock 19 步短回合验证实际 m=3 与 terminal。t=5／8 磁盘快照恢复，保存 pending／held speed／父历史与物理执行器，验证剩余轨迹和最终字段相同。恢复不额外 reset。
