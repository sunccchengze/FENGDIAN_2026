# 桨距误差记忆消融与参数漂移结果

2026-11-05。**关闭记忆输入仍保留了大部分验证集终点退化。** 真实记忆在验证慢变总体上有闭环补偿作用，但随训练减弱，且作用方向随流和案例而变。已有证据优先指向续训策略的保留约束。具体是哪部分训练信号推动旧参数漂移仍未识别。默认策略沿用既有配置。[事前协议](PITCH_ERROR_MEMORY_ABLATION_PROTOCOL.md) · [正式配对训练](PITCH_ERROR_MEMORY_FORMAL_RESULTS.md)

## 冻结范围与配对定义

使用原 n8 父和正式两臂检查点，覆盖原 36 个已知开发槽位、18 个 validation 槽位以及三条流。正常记忆、独立训练恒零、父和 P／PI 均复用既有完整轨迹。验证集父轨迹来自形式一致的初始记忆策略，全部原参数与父逐张量相等，初始记忆权重为 0。恒零与记忆初始验证轨迹也逐行相等。只有同记忆权重读取 0 的 324 回合是本轮新增轨迹。每步读取反事实闭环自己的观测，内部继续按当前误差和执行器收到的桨距命令维护 I。校验了全部首步桨距命令与正常记忆轨迹相等，以及全过程来流和偏航相等。[冻结配置](../experiments/20261105_pitch_memory_ablation/config.yaml) · [轨迹身份和校验和](../experiments/20261105_pitch_memory_ablation/trajectory_manifest.json)

下文的「正常−读 0」表示相同权重下读取真实 I 的闭环差异。「读 0−恒零」是共同读取 0 时两份续训权重的闭环差异，随闭环观测分布改变，包含训练路径和参数差异。两个均值差可在同一组槽位上做算术相加。此构造只识别冻结权重后的输入干预，训练路径、Actor 和 Critic 的贡献仍不能据此分别归因。

## 离线权重、I 分布和同状态探针

18 个正式角色的回放状态、两臂合计 98,304 个正式训练转移及已有验证时序参与离线审计。继承回放按观测中的归一化目标折算为最接近的整瓦，无法从检查点恢复完整风况身份的样本单列。三流记忆新训练中 I 触到任一 ±.02 rad 边界的比例分别为 17.41%、22.06%、20.70%，与当前有符号误差的 Pearson r 为 .215、.250、.245。验证慢变 `final` 流 0 有 54.04% 决策点在 +.02，3.91% 在 −.02，对应记忆 `selected` 为 24.61% 和 20.57%。同一验证慢变角色内三个流的 I 与误差相关从 .302 到 .550。触边与误差关联均随流、风况和目标变化，无法单独判定闭环收益。[校正后积分分布](../experiments/20261105_pitch_memory_ablation/integrals_verified.csv)

记忆组原 Actor 参数相对初始的 L2 漂移比例在九个 Actor 上平均从 12.77% 增至 20.16%，Critic 从 20.68% 增至 31.80%。新增 Actor 权重范数范围从 .155–.238 变为 .187–.415，新增 Critic 权重从 .275–.704 变为 .533–.926。每个 Actor、Critic 和目标网的范数、相对漂移及 selected→final 漂移均逐机保存。[参数漂移表](../experiments/20261105_pitch_memory_ablation/weights.csv)

同状态探针使用 6,144 条保存的完整训练观测。每条流的两种续训方法和 n8 父共用锚点与记录联合动作。既有验证时序缺少完整有效风速字段，因此验证用于分布统计和闭环比较。记忆 `selected`／`final` 的真实 I 对三机桨距目标的平均绝对即时作用为 6.36／7.13 mrad。同状态统一读 0 时，记忆相对独立训练恒零仍差 13.96／19.39 mrad，相对父差 25.65／33.64 mrad。

## 后续只保留一项候选

**冻结各自 n8 父的 Actor 原权重，只训练现有 Actor 记忆支路。** 对照沿用本轮真实记忆的全量 Actor 更新，双方均读取真实 I，Critic、回放、奖励、采样、学习率和执行器沿用同一配置。约束组的 Actor 主干及相应目标网主干固定在各自父策略。这样在 I=0 时可直接核验 Actor 输出与父一致，同时允许学习 I 在不同状态下的作用。此候选只针对观察到的原策略漂移，所需效果仍应由配对训练及事前门槛检验。本轮无实现、训练、蒸馏或新测试。
