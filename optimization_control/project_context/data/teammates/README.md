## 通用格式要求（所有队友）

1. 数据文件推荐 `.csv`（表格）或 `.npz`（数组），模型文件 `.pt` / `.onnx`
2. **每个文件必须附带同名 `.json` 元数据**，至少包含：
   - `source`：提供人
   - `date`：生成日期
   - `description`：内容描述
   - `fields`：字段/变量含义与单位
   - `normalization`：归一化参数（mean/std，如有）
   - `operating_condition`：风况、布局等条件
3. 数据不满足格式时会被退回，请先看 `CLAUDE.md` 第六节
