## 模型说明（厉今飞填写）

- 训练数据来源：袁夫达 FLORIS 数据，GCH / CC **各训一套独立模型**（零功率行已剔除：
  GCH 用 1202 行、CC 用 1220 行）
- 模型结构：输入 6 个工程特征 → Normalization → Dense(64, Swish) → Dense(128, Swish)
  → Dense(64, Swish) → Dense(3, Sigmoid) → 三台风机功率 → 固定求和层 → farm_power
- 输入特征与顺序：`[wind_speed, turbulence_intensity, sin(dir), cos(dir), sin(2*dir), cos(2*dir)]`
  （风向经 sin/cos 编码；布局固定故不含坐标）
- 输出含义：turbine_1/2/3_power + farm_power，单位 W（按额定 5MW/15MW 缩放，见
  `model_metadata.json` 的 `output_scales_W`）
- 超参：70/15/15 划分（seed=42）、Adam、lr=0.001、MSE、Swish、输出 Sigmoid、L2 正则、
  EarlyStopping、ReduceLROnPlateau、恢复验证集最优模型
- 测试指标（R² / MAE）：
  | 模型 | 单机 R² | 单机 MAE (kW) | farm R² | farm MAE (kW) |
  |------|---------|---------------|---------|---------------|
  | GCH  | 0.9985~0.9988 | ~33-35 | 0.9991 | 86.5 |
  | CC   | 0.9980~0.9983 | ~40-41 | 0.9987 | 103.1 |
- 依赖版本：TensorFlow/Keras（`.keras` 格式），详见训练脚本

## 模型设计说明（厉今飞，2026-08-07）

> 以下为厉今飞对模型设计的原始说明（2026-08-07 补充），与上表互为印证，冲突时以此为准：

> 本研究采用多层全连接神经网络建立风况参数与风机输出功率之间的非线性映射。原始输入包括风速、风向和湍流强度。考虑到风向变量具有周期性，将其采用正余弦周期编码并加入二阶谐波特征，因此网络输入层包含6个特征。针对清洗后约1220组样本，采用中小规模的多层感知机结构，以避免网络容量过大导致过拟合，同时保证模型具有足够能力描述风速、风向、湍流强度及其耦合作用产生的非线性功率响应。

> 隐藏层采用Swish激活函数，以获得良好的非线性表达能力和梯度传播性能；输出层采用Sigmoid激活函数。由于单台风机输出功率存在0至5 MW的物理范围，训练前将功率按照额定功率归一化至0～1区间，Sigmoid函数的输出范围与归一化功率范围一致，从而能够从网络结构上限制预测功率不低于0且不超过额定功率。风场总功率则由三台风机预测功率直接求和获得，以保证模型输出满足功率守恒关系。

**设计要点提炼**：

1. **输入编码**：原始 3 参数（风速/风向/湍流强度），风向经正余弦周期编码 + 二阶谐波 → 6 特征（对应 `model_metadata.json` 的 `engineered_features`）
2. **网络规模**：中小规模 MLP（64→128→64），针对 ~1220 组样本防过拟合
3. **激活函数**：隐藏层 Swish（非线性+梯度传播好）；输出层 Sigmoid
4. **物理约束内建**：功率按额定 5MW 归一化到 0~1，Sigmoid 输出天然限制在 [0, 额定]，
   网络结构上保证预测功率不越物理边界
5. **功率守恒**：全场功率 = 三台单机功率直接求和（模型不单独预测 farm_power，
   该列为求和得到，保证守恒）

## 控制模块可用性结论（2026-08-23）

该模型是固定布局下的稳态功率预测器。输入不含偏航、桨距或转速，不能直接作为 RL 动作响应模型；后续应基于含控制参数数据重训，而不是只把现有 6 特征网络包进 Gym 环境。
