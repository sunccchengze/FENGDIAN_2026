| 1. 项目简介（200字以内）   风能的高效利用是实现双碳目标的关键，基于中国能源转型需求，风电技术正向着大规模、集群化和智能化方向发展，同时对风电机组的安全性和经济性提出了更高要求。大型风电场中，机组间尾流干扰导致流场分布不均，传统调控方式难以精准匹配电网功率需求。本项目面向未来风电智能运维系统，尝试研究融合数据-物理驱动的风电流场智能感知与智能调控技术，通过构建风电场流场智能分析模型，精准捕捉流场分布特征与机组高效运行耦合关系；进而对风电机组的功率输出、转速、桨距角、偏航角等参数进行智能调控，实现电网需求与风电输出的精准匹配，为大型风电场稳定可控运行提供技术支撑，助力风电产业向高效化、智能化升级。 | | | | | | | | | | | |
| 二．项目相关研究现状及发展动态（不少于200字）  随着风电机组单机容量向10 MW级以上迈进以及风电场向深远海与复杂地形区域拓展，风机尾流效应已成为制约全场发电效率与机组疲劳寿命的关键因素[1]。尾流不仅导致下游机组入流风速降低、湍流强度增加，引发显著的功率损失[2][3]，还会因尾流冲击与涡激振动加剧关键部件的疲劳载荷。在此背景下，实现尾流场的实时精确感知与基于尾流感知的全场功率协同分配[4]，已经成为当下风电研究领域的重点[5]。  尾流场的动态特性具有典型的三维性、时变性与强非线性特征，导致其准确监测技术面临核心瓶颈问题。目前主要采用基于激光雷达的直接测量技术，通过多光束扫描获取风机前方多距离门处的视线风速[6][7]，实现尾流剖面感知与入流前馈控制。该技术可支撑尾流跟踪与偏航校正，研究表明基于LiDAR的前馈控制可有效降低整体疲劳载荷约6%[8]。然而，其数据可用率非常有限、成本高企，致使其在实际工程应用中落地困难，尤其是激光雷达技术集中于机组的前馈控制，使其难以与后续的功率调配实现闭环。  传统的计算流体力学能够精确解析尾流中的湍流结构、叶尖涡演化及尾流蜿蜒现象[9]。然而，其计算成本极高[10]，单工况模拟需数小时至数天，无法满足实时控制需求。于是，针对以上挑战，我们提出将神经网络与CFD等计算流体力学进行融合，利用CFD提供高质量训练数据与物理先验知识，利用神经网络实现快速推理与非线性映射，最终构建兼具精度、效率与物理一致性的尾流预测与控制系统。  现有偏航控制[11]多依赖离线优化的偏航表或基于简化模型的在线优化，未能将实时尾流感知信息动态融入控制决策，导致感知与控制环节在时间尺度与数据粒度上不匹配。  近年来，神经网络因其强大的非线性拟合能力，在尾流场快速预测领域展现出巨大潜力[12][13][14]，采用深度学习方法能够建立从入流条件、机组运行参数到尾流速度场分布的端到端映射[15]。卷积神经网络被用于提取尾流场的空间特征，实现对速度亏缺剖面与湍流强度分布的快速预测；长短期记忆网络与Transformer则被用于捕捉尾流蜿蜒的时间演化规律。研究表明，基于神经网络的代理模型可在毫秒级时间内完成单机尾流预测，较之大涡模拟加速数个数量级，同时保持较高的预测精度。然而，其尚存在可解释性差、外推能力弱、对物理约束的遵守不确定等缺陷，难以对外迁移。  与纯数据驱动分析方法相比，物理增强型人工智能技术如物理信息神经网络(Physics-Informed Neural Networks, PINN)[16-17]通过融合物理机理与神经网络深度学习技术，将守恒方程、本构关系等物理先验知识内嵌于神经网络模型训练中，既保证了模型分析结果的物理规律遵循性和物理可解释性，又充分利用了神经网络强大的数据解耦和函数逼近能力，突破了纯数据驱动方法在数据稀缺或多物理场耦合时的局限性，可为工程领域复杂系统装备的多目标协同优化设计、复杂非线性方程组求解与高保真快速分析提供创新解决方案：首先数据驱动分析技术可针对已有研究数据进行系统性归纳总结，挖掘数据中隐藏的潜在规律，理清复杂系统内关键参数的演变规律及其影响控制机制；其次，利用物理增强型人工智能技术如物理信息神经网络(Physics-Informed Neural Network, PINN)等，将物理规律和机理模型嵌入机器学习过程，可在保障物理一致性和可解释的前提下，实现高效、高精度求解高维非线性复杂数理模型；最后，基于PINN模型可进一步开发包含物理信息的启发式优化算法，实现对复杂耦合目标参数进行全局寻优，从而提高系统分析精度，加速完成复杂系统分析。综上，AI赋能的数据-物理融合驱动技术是实现风电流场智能感知与智能调控技术的完美选择，可为风电场运维系统智能化升级提供理论支撑与技术支持。  *(图片 · 见原文件 20260329-大创申请书-终版.docx)*  物理信息神经网络架构示意图  *(图片 · 见原文件 20260329-大创申请书-终版.docx)*  风电机组的偏航控制结构  [1].潘杰. 考虑风场预测的风电场实时协同控制研究[D]. 重庆:重庆大学,2024. | 三、项目实施的目的、意义（不少于200字）  项目目的：  本项目面向未来风电智能运维系统，旨在突破大型风电场流场分析与机组调控的技术瓶颈，研究融合数据-物理驱动的风电流场智能感知与智能调控技术，实现风电输出与电网需求的智能匹配，为大型风电机组高效运行提供技术支撑。核心目标包括：  (1)构建基于神经网络的风电场流场高精度分析模型，实现流场分布的实时精准预测；  (2)建立流场特征与机组运行参数的耦合关联机制，开发机组动态微调算法；  (3)最终形成 “流场分析 - 需求匹配 - 精准调控” 的技术体系，为提升风电消纳效率与电网运行安全性提供支持。  项目意义：  在风电规模化发展背景下，大型风电场的流场干扰问题日益突出，传统依赖经验或简化模型的调控方式，存在响应滞后、精度不足等缺陷，导致风电输出波动性大，难以满足电网对供电稳定性的要求，制约了风电的大规模并网消纳。  本项目的实施具有重要的技术创新价值与工程应用意义：技术层面，将神经网络等 AI 技术与风电场流场分析、机组调控深度融合，突破传统CFD仿真和数理分析的局限性，提升流场预测与调控决策的精准度和实时性，丰富风电智能化运维的技术路径；应用层面，通过动态微调机组运行参数，可显著降低流场干扰带来的功率损失，实现风电输出与电网需求的精准匹配，提升风电场的发电效益与电网接纳能力，为风电产业的高质量发展提供技术保障，助力能源转型与双碳目标的实现。 | | | | | | | | | | | |
| 四、项目研究内容和拟解决的关键问题（不少于300字）  （一）主要研究内容  本项目旨在构建一套融合神经网络与CFD的尾流预测、偏航控制一体化框架，突破传统工程尾流模型精度不足与纯CFD计算效率低下的双重瓶颈，实现风电场尾流场的实时精准感知与偏航角协同优化，在提升全场发电效率的同时兼顾功率调配。以下为主要研究内容：  1、首先耦合CFD数值仿真和理论分析，构建数据-物理驱动的神经网络尾流代理模型,建立从偏航角、入流条件到尾流速度场分布的快速、高精度映射模型，拟将尾流预测误差控制在5%以内，较纯数据驱动模型数据精度提升5%以上。  2、偏航角的实时优化控制：将神经网络代理模型嵌入优化框架，实现偏航角组合的动态 求解，实现能够在输入不同风况的条件下自动输出各个风机的最优偏航角，使全场发电量 提升。  3、基于功率需求的偏航角实时控制：构建一个风电场的线上运维系统，通过输入目前所 需求的功率，系统能够实时输出并调整各个风机的偏航角，使整个风电场达到运作的最佳 状态，实现风电场的智能运维。  *(图片 · 见原文件 20260329-大创申请书-终版.docx)*  主要研究内容图示  （二）拟解决的关键问题  1、数据采集与处理：多数研究使用自建仿真数据或单一风电场实测数据，结果难以复现与对比，如何从海量多源数据中精准提取关键信息，能够准确用于尾流模型构建和分析决策成为问题。此外，在模型优化过程中，需反复调用神经网络进行预测，而高维模型的计算成本过高，且难以满足对实时性的严格要求，这些需要通过数据预处理、特征提取和降维技术等方法，使尾流模型构建兼顾精度和复杂度。  2、模型的建立与融合：尾流场具有强非线性、多尺度耦合、长时序依赖等复杂特性。如何设计神经网络架构，准确捕捉尾流场的演化规律，是实现精准预测的关键问题。此外，如何设计有效的融合架构，既利用CFD数据的高保真性，又保持神经网络的高效率与泛化能力，也是需要集中研究的问题。 | | | | | | | | | | | |

| 六、项目实施方案 本项目旨在开发一套风电场实时功率智能控制系统，通过“感知-建模-优化-验证”的技术路径，实现风机功率的精准、协同调控。具体实施方案如下：  步骤一：物理建模与高保真流场数据生成  利用开源计算流体力学软件 OpenFOAM建立风电机组三维几何模型及流体计算域。设计包含不同风速、偏航角、桨距角及转速的 CFD 算例矩阵。利用大涡模拟（LES）开展高保真并行计算，获取动态尾流演化的时空流场快照，为后续数据驱动算法提供高质量的底层数据基座。  步骤二：数据降维与数字风场重构  针对 CFD 海量数据导致的算力瓶颈，引入本征正交分解（POD）对高维流场进行降阶处理，提取包含流场主要能量的关键特征模态。将降维后的特征系数输入多尺度物理信息神经网络（PINN）。该网络以Navier-Stokes方程为物理约束，深度融合仿真与实测特征，构建能够高精度反映风场时空变化与尾流效应的轻量化数字风场。  步骤三：风机气动特性精准建模与代理模型降阶  基于生成的数字风场，应用叶素-动量理论（BEM）建立单台风机的气动载荷模型，耦合动态尾流模型以量化机组间的气动干扰。为解决高精度物理模型难以在线应用的问题，训练轻量化代理 PINN 模型替代传统 CFD/BEM 计算，将流场演化与气动载荷的单步计算时间从小时级压缩至毫秒级。  步骤四：单风机智能响应模型开发  基于建立的毫秒级代理模型，以精准跟踪电网下发的发电指令为核心目标，利用近端策略优化（PPO）等强化学习算法，在线滚动优化单机的桨距角与转速设定值，形成具备环境自适应能力、可实时响应的单风机智能调控器。  步骤五：基于偏航协同的风电场多机功率分配  为实现全场发电功率的按需可控与最优分配，构建包含所有风机空间位置、流场信息及电网约束的全局协同优化环境。应用多智能体深度确定性策略梯度（MADDPG）算法，将每台风机视为一个独立智能体。通过智能体间的经验共享与分布式决策，训练出基于主动偏航（尾迹转向）与变桨联合调节的协同控制策略，在满足电网总功率需求的前提下平抑输出波动。  步骤六：系统集成与虚实闭环验证  将上述算法模块封装，构建完整的多机协同功率控制数字孪生仿真平台。同时，在实验室搭建包含 3 × 3阵列微型风机、风洞与多通道测控系统的物理实验平台，开展半实物仿真。实现“虚拟仿真-物理验证”的双向闭环，最终验证系统在功率可控性的整体性能。  *(图片 · 见原文件 20260329-大创申请书-终版.docx)* | | | | | | | | | | | |

| 九、项目研究进度安排及各阶段预期成果(本栏内容为中期检查及结题答辩重要参考)  第一阶段：物理建模与 CFD 算例矩阵设计（2026年4月—2026年6月）  任务：建立风电机组三维模型及流体计算域；设计涵盖多风速、多偏航角及不同桨距角的 CFD 算例矩阵；配置 OpenFOAM 及深度学习环境。  预期成果：确定风机参数与网格划分规范；完成CFD数值模拟验证报告。  第二阶段：大规模 CFD 仿真与“物理-数据”库构建（2026年7月—2026年9月）  任务：利用暑期集中算力开展大涡模拟（LES），获取动态尾流演化数据；提取流场快照，利用 POD 提取主特征模态，完成流场降阶。  预期成果：建成包含 200+ 典型工况的高保真风场动态尾流数据库；输出《风机尾迹特征提取与降维分析报告》。  第三阶段：代理模型开发与单机控制训练（2025年10月—2025年12月）  任务：基于降阶流场数据训练代理 PINN 模型；开发基于 PPO 的单机智能控制器，在线 滚动优化桨距角与转速，完成单机功率精准跟踪的闭环测试。  预期成果：形成《单机智能调控算法验证报告》；申请《基于代理模型的风机实时气动调控软件》计算机软件著作权 1 项。  第四阶段：多智能体功率协同算法开发与测试（2027年1月—2027年3月）  任务：构建包含多台风机的阵列仿真环境；实现 MADDPG 算法的编码与部署；训练并对比群体偏航协同策略在“最大功率追踪”与“指定功率分配”两种模式下的控制效果。  预期成果：输出《风电场多机功率协同优化仿真报告》（验证全场功率可控性与提升指标）；形成核心学术论文初稿 1 篇。  第五阶段：系统集成与虚实闭环物理验证（2027年4月—2027年5月）  任务：在实验室搭建微缩风洞与阵列风机测控平台；将算法部署于数字孪生控制看板；开展半实物仿真联调，验证系统对真实环境噪声的抗干扰能力及功率调度的实时响应能力。  预期成果：产出“多机协同智能功率控制与数字孪生演示平台” 1 套；形成《智能控制系统虚实闭环验证报告》。  第六阶段：项目总结与成果答辩（2027年6月）  任务：整理全套 CFD 算例代码、AI 算法源码与实验视频；完善并投递学术论文；撰写结题报告，准备验收答辩。  预期成果：完成学术论文初稿与项目结题报告，通过结题答辩。 | | | | | | | | | | | |
