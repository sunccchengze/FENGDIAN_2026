## 什么时候放在这里

- 阶段总结、答辩 PPT、申报书和正式对外提交版本；
- 多人共同产出的图表、讲稿、联合报告和提交快照；
- 需要在项目层面冻结的版本，而不是个人工作草稿。

如果材料主要由一人制作但包含其他成员结果，应保留在该成员目录，同时在本目录建立引用或提交快照，不要复制出两个互相漂移的“最终版”。

## 集体材料提交要求

1. 创建材料 Issue，写清受众、截止时间、格式和参与成员；
2. 登记源文件、生成文件、提交快照和代码/数据版本；
3. 关键数字链接 `docs/evidence/`；
4. 每个领域由对应主责人确认，至少两名成员审阅；
5. 提交后冻结快照，不覆盖历史版本，不使用 `final_v2` 等含糊命名。

通用材料规则见 [`../README.md`](../README.md)，材料记录模板见 [`../../docs/templates/材料记录模板.md`](../../docs/templates/材料记录模板.md)。
