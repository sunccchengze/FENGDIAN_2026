# 袁夫达 · 个人材料目录

> 这里是袁夫达负责或需要审阅的降阶模型与代理模型材料入口。目录责任不等于个人拥有全部模型代码、训练数据或实验事实。

## 当前状态

当前 checkout 尚未登记一份明确归属于袁夫达的独立成品。此状态只表示材料索引尚未补齐，不表示外部位置没有材料。

## 后续应放入的内容

- POD/ROM、降阶建模和代理模型说明；
- 特征、训练/测试划分、误差、基线和适用域；
- 不能外推的边界、失败尝试和模型限制；
- 供阶段总结、答辩或论文引用的审阅版图表和报告。

模型权重、训练数据和大体积中间产物先按数据治理规则登记，不以 `xx.md` 或材料 PDF 代替原始证据。

## 提交方式

1. 创建实验/材料 Issue，关联数据版本和代码 commit；
2. 将源文件或正式导出物放入本目录；
3. 在 `docs/evidence/` 登记误差、适用域和复现命令；
4. 由袁夫达确认模型内容，再由至少一名其他成员复核；
5. 通过 PR 后再在集体材料中引用。

通用材料规则见 [`../README.md`](../README.md)，证据模板见 [`../../docs/templates/证据卡模板.md`](../../docs/templates/证据卡模板.md)。
