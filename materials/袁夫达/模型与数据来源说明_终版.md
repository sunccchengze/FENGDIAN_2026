# 1. 模型描述

本数据由美国国家可再生能源实验室（NREL）开源的风电场工程仿真框架 FLORIS（v4）生成，用于描述三台风机之间的尾流相互作用及全场功率。仿真采用两套解析尾流模型：GCH（Gauss Curl Hybrid）与 CC（Cumulative Curl），二者共享风轮与布局设置，仅尾流速度亏损的刻画方式不同。每个工况在给定来流条件（风速、风向、湍流强度）下，输出每台风机的功率与全场总功率。

## 2.1 关键参数：有效速度亏损强度 C

有效速度亏损强度 C 无量纲，等于尾流中心处的速度亏损与来流之比：C = 1 表示中心速度被完全抵消，C = 0 表示无亏损。它刻画“尾流中心被削弱的相对深度”，是决定下游风机入流速度的关键量。在 GCH 中由推力系数与尾流宽度按高斯公式给出；在 CC 中另乘以 (1−Σλ) 计入前序风机的累积亏损。具体表达式见第 3.3、3.4 节。

# 3. 理论方程与公式

## 3.1 动量理论基础（致动盘）

风轮视为一维致动盘。定义轴向诱导因子 a，盘面与远尾流速度分别为：

$$u\_{R} = U\_{\infty }(1 − a) , u\_{0} = U\_{\infty }(1 − 2a)$$

推力与功率及其系数：

$$T = ½ρAU\_{\infty }^{2} · 4a(1 − a)$$

$$P = ½ρAU\_{\infty }^{3} · 4a(1 − a)^{2}$$

$$C\_{T} = \frac{T}{½ρAU\_{\infty }^{2}} = 4a(1 − a) , C\_{P} = \frac{P}{½ρAU\_{\infty }^{3}} = 4a(1 − a)^{2}$$

功率系数上限即贝兹极限（令 dC\_P/da = 0，得 a = 1/3）：

$$C\_{P,max} = \frac{16}{27} ≈ 0.5926$$

工程中由推力系数反解轴向诱导因子：

$$a = ½\left(1 − \sqrt{1 − C\_{T}}\right)$$

风速随高度按幂律变化（风切变，α = 0.12）：

$$U\left(z\right) = U\_{hub}\left(\frac{z}{z\_{hub}}\right)^{α}$$

## 3.2 高斯分布基础

尾流速度亏损沿横向近似呈高斯分布，其一维剖面为：

$$f(y) = \frac{1}{σ\sqrt{2π}}exp\left(−\frac{\left(y − μ\right)^{2}}{2σ^{2}}\right)$$

对应地，尾流中心亏损为 C、宽度为 σ 时，任意点的速度亏损：

$$\frac{Δu}{U\_{\infty }} = Cexp\left(−\frac{r^{2}}{2σ^{2}}\right)$$

## 3.3 GCH 尾流模型（velocity = gauss + 涡量修正）

GCH 采用经典高斯速度亏损，并在其上叠加涡量修正刻画偏航引起的横向速度与二次偏转。有效速度亏损强度：

$$C = 1 − \sqrt{1 − \frac{C\_{T}cosγ}{8σ\_{y}^{2}σ\_{z}^{2}/D^{2}}}$$

考虑风切变与风偏 φ 的椭圆高斯径向坐标（含 a、b、c 系数）：

$$r^{2} = a\left(y − y\_{i} − δ\right)^{2} − 2b\left(y − y\_{i} − δ\right)\left(z − z\_{i}\right) + c\left(z − z\_{i}\right)^{2}$$

$$a = \frac{cos^{2}φ}{2σ\_{y}^{2}} + \frac{sin^{2}φ}{2σ\_{z}^{2}}$$

$$b = \frac{−sin2φ}{4σ\_{y}^{2}} + \frac{sin2φ}{4σ\_{z}^{2}}$$

$$c = \frac{sin^{2}φ}{2σ\_{y}^{2}} + \frac{cos^{2}φ}{2σ\_{z}^{2}}$$

初始尾流宽度由动量平衡给出，近 / 远尾流分界为 x₀，远尾流宽度随下游线性扩展：

$$u\_{R} = U\_{\infty }\frac{C\_{T}}{2\left(1 − \sqrt{1 − C\_{T}}\right)}$$

$$u\_{0} = U\_{\infty }\sqrt{1 − C\_{T}}$$

$$σ\_{z0} = \frac{D}{2}\sqrt{\frac{u\_{R}}{U\_{\infty } + u\_{0}}}$$

$$σ\_{y0} = σ\_{z0} cosγ · cosφ$$

$$x\_{0} = x\_{i} + \frac{Dcosγ\left(1 + \sqrt{1 − C\_{T}}\right)}{\sqrt{2}\left(4α·TI + 2β\left(1 − \sqrt{1 − C\_{T}}\right)\right)}$$

$$k = k\_{a}·TI + k\_{b}$$

$$σ\_{y} = k\left(x − x\_{0}\right) + σ\_{y0}$$

最终高斯速度亏损为：

$$Δu = Cexp\left(−\frac{r^{2}}{2σ^{2}}\right)$$

GCH 高斯模型的参数含义（gch.yaml）：α、β 决定近/远尾流分界 x₀（见上式），其中 α 放大湍流强度项、β 放大诱导因子项；k\_a、k\_b 决定尾流宽度扩展率 k = k\_a·TI + k\_b，k\_a 放大湍流增强、k\_b 为基础扩展率（与 CC 的 a\_s、b\_s 作用类似）。偏转模型参数 d\_m 缩放偏航偏转量、a\_d、b\_d 为附加横向偏置（本数据 γ = 0°，偏转可忽略）。

### 3.3.1 尾流偏转（deflection = gauss）

偏航引起的偏斜角、初始偏转、近尾流与远尾流偏转：

$$θ\_{c0} = d\_{m}\frac{0.3γ}{cosγ}\left(1 − \sqrt{1 − C\_{T}cosγ}\right)$$

$$δ\_{0} = tanθ\_{c0}\left(x\_{0} − x\_{i}\right)$$

$$δ\_{near} = \frac{x − x\_{i}}{x\_{0} − x\_{i}}δ\_{0} + a\_{d} + b\_{d}\left(x − x\_{i}\right)$$

$$C\_{0} = 1 − u\_{0}/U\_{\infty } , M\_{0} = C\_{0}\left(2 − C\_{0}\right) , E\_{0} = C\_{0}^{2} − 3e^{\frac{1}{12}}C\_{0} + 3e^{\frac{1}{3}}$$

$$δ\_{far} = δ\_{0} + θ\_{c0}E\_{0}/5.2\sqrt{\frac{σ\_{y0}σ\_{z0}}{k\_{y}k\_{z}M\_{0}}} ln\left(\frac{\left(1.6 + √M\_{0}\right)\left(1.6\sqrt{\frac{σ\_{y}σ\_{z}}{σ\_{y0}σ\_{z0}}} − √M\_{0}\right)}{\left(1.6 − √M\_{0}\right)\left(1.6\sqrt{\frac{σ\_{y}σ\_{z}}{σ\_{y0}σ\_{z0}}} + √M\_{0}\right)}\right) + a\_{d} + b\_{d}\left(x − x\_{i}\right)$$

### 3.3.2 涡量修正与二次偏转（curl / secondary steering）

偏航使风轮上下产生反向涡量，这些涡诱导横向速度、改变尾流位置并加速恢复。涡环强度、旋转涡及 Lamb–Oseen 涡核：

$$Γ = \frac{π}{8}DuU\_{\infty }C\_{T}$$

$$Γ\_{wr} = \frac{π}{2}Da(1 − a)\frac{ū}{TSR}$$

$$F\_{core} = 1 − exp\left(−\frac{r^{2}}{ε^{2}}\right)$$

由涡诱导的横向速度（V = Γz/(2πr²)·F\_core·decay）及其下游衰减（混合长度湍流，κ = 0.41，λ\_m = D/8）：

$$V = \frac{Γz}{2πr^{2}}F\_{core} · decay$$

$$λ\_{m} = \frac{D}{8}$$

$$l\_{m} = \frac{κz}{1 + κz/λ\_{m}}$$

$$ν = l\_{m}^{2} |\frac{du}{dz}|$$

$$decay = \frac{ε^{2}}{4ν\frac{Δx}{U\_{\infty }} + ε^{2}}$$

由横向速度反推等效偏航角（二次偏转），并以湍动能折算偏航附加湍流强度：

$$γ\_{added} = ½ arcsin\left(\frac{2\left(⟨v⟩ − v\_{core}\right)}{v\_{top} + v\_{bottom}}\right)$$

$$k = \frac{\left(ūI\_{i}\right)^{2}}{2/3}$$

$$I\_{total} = \frac{\sqrt{\frac{2}{3}k\_{total}}}{ū}$$

$$I\_{mixing} = I\_{total} − I\_{i}$$

### 3.3.3 湍流与组合

尾流附加湍流强度（Crespo–Hernández；GCH 的 gch.yaml：C\_const = 0.5，ai = 0.8，initial = 0.1，downstream = −0.32）：

$$ΔI = C\_{const} · a^{ai} · TI\_{ambient}^{initial} · \left(Δx/D\right)^{downstream}$$

多机尾流按平方和叠加（SOSFS），并与自由流合成最终流场：

$$Δu\_{total} = \sqrt{\sum\_{i}^{\infty }Δu\_{i}^{2}}$$

$$u(x,y,z) = \sqrt{u\_{free}^{2} + Δu\_{total}^{2}}$$

## 3.4 CC 尾流模型（velocity = cc，超高斯累积）

CC 采用超高斯剖面刻画近尾流的“平顶”亏损，并显式累积所有上游风机的亏损。超高斯速度亏损：

$$Δu = Cexp\left(−\frac{r̃^{n}}{2σ^{2}}\right)$$

无量纲径向距离 r̃ 把径向距离除以风轮直径归一化，便于统一比较不同尺寸风机；尾流扩展与形状指数由 a\_s、b\_s、c\_s1、c\_s2、a\_f、b\_f、c\_f 七个参数控制：

$$r̃ = \frac{\sqrt{\left(y − y\_{i} − δ\right)^{2} + \left(z − z\_{i}\right)^{2}}}{D}$$

$$β = \frac{0.5\left(1 + \sqrt{1 − C\_{T}}\right)}{\sqrt{1 − C\_{T}}}$$

尾流扩展 k 与初始尾流宽度 ε：其中 a\_s、b\_s 决定扩展率（a\_s 放大湍流效应、b\_s 为基础率），c\_s1、c\_s2 决定初始宽度（c\_s1 随 C\_T 变化、c\_s2 为常数）：

$$k = a\_{s}·TI + b\_{s}$$

$$ε = \left(c\_{s1}C\_{T} + c\_{s2}\right)\sqrt{β}$$

$$σ = k·x̃ + ε , x̃ = |Δx|/D$$

超高斯形状指数 n 由 a\_f、b\_f、c\_f 控制：a\_f 为幅值、b\_f 为随下游衰减率、c\_f 为渐近值；n = 2 即高斯剖面，n > 2 为近尾流的“平顶”剖面，随下游衰减回落到高斯。

$$n = a\_{f}exp\left(b\_{f}x̃\right) + c\_{f}$$

中心线强度显式累积前序（m = 1, …, i−1）风机的亏损 λ（S = σ\_n²+σ\_m²）：

$$S = σ\_{n}^{2} + σ\_{m}^{2}$$

$$Y\_{m} = \frac{\left(y\_{i} − y\_{m} − δ\right)^{2}}{2S}$$

$$Z\_{m} = \frac{\left(z\_{i} − z\_{m}\right)^{2}}{2S}$$

$$λ\_{m} = \frac{σ\_{m}^{2}}{S} exp\left(−Y\_{m}\right) exp\left(−Z\_{m}\right)$$

$$Σλ = \sum\_{m}^{i−1}λ\_{m}\frac{C\_{m}}{u\_{initial}}$$

于是中心线强度（a₁ = 2^(2/n−1)，a₂ = 2^(4/n−2)，Γ 为伽马函数）：

$$a\_{1} = 2^{\frac{2}{n} − 1}$$

$$a\_{2} = 2^{\frac{4}{n} − 2}$$

$$C = a\_{1}\left(1 − Σλ\right) − \left(1 − Σλ\right)\sqrt{a\_{2} − \frac{nC\_{T}cosγ}{16Γ\left(\frac{2}{n}\right)σ^{\frac{4}{n}}\left(1 − Σλ\right)^{2}}}$$

CC 的偏转、湍流、组合分别与 GCH 相同（gauss / crespo\_hernandez / sosfs）；注意 cc.yaml 的湍流参数与 GCH 不同（C\_const = 0.9、ai = 0.83、initial = 0.01、downstream = −0.25）。

# 4. 计算顺序与结果

给定一个工况（风速、风向、湍流强度），按如下顺序求解，得到每台风机功率与全场功率。对应公式见第 3 章各节。

## 4.1 求解顺序

第 0 步（输入）：来流风速 U∞、风向、湍流强度；布局固定（T1 上游，T2、T3 依次下游）。

第 1 步（单机气动）：由 U∞ 查功率 / 推力曲线得 C\_P、C\_T，再由 C\_T 反解诱导因子 a = ½(1−√(1−C\_T))（见 3.1）。

第 2 步（尾流初始化）：由 3.3 / 3.4 计算上游风机的初始尾流宽度 σ 与有效速度亏损强度 C。

第 3 步（传播与叠加）：沿风向自上游到下游，按 SOSFS 平方和叠加各上游尾流亏损，得每机盘面有效风速 u\_eff,i（见 3.3.3 的组合公式）。

第 4 步（功率）：P\_i = ½ρA·u\_eff,i³·C\_P(u\_eff,i)，接近额定后限功率（见 3.1）。

第 5 步（全场）：P\_farm = Σ P\_i（见 3.1）。

## 4.2 结果形态

每个工况输出 4 维结果：3 台单机功率与全场总功率（单位 W）。物理特征：下游机功率随其与上游机相对方位连续变化，尾流完全对齐时功率最低（损失可达 80% ~ 90%）；风向偏转使尾流错开后功率回升；湍流越大，尾流恢复越快、全场功率越高。例如 8 m/s、270°、TI = 0.06 时全场约 2.23 MW，TI 增至 0.10 时约 2.46 MW。

# 5. 数据生成与结构

## 5.1 生成流程

脚本 generate\_data.py 的执行步骤：

1. 加载模型配置（FlorisModel）；GCH 用 inputs/gch.yaml，CC 用 inputs/cc.yaml。

2. 设置 3 台 NREL 5MW 布局，间距 3D ≈ 378 m。

3. 用 np.meshgrid 生成 1224 个工况（风速 × 风向 × 湍流强度），批量 set 并运行 fmodel.run()。

4. 读取每台风机功率 fmodel.get\_turbine\_powers() 与全场功率 fmodel.get\_farm\_power()。

5. 汇总写入 training\_data\_gch.csv（或对应 CC 文件）。

## 5.2 数据结构（CSV）

|  |  |  |  |
| --- | --- | --- | --- |
