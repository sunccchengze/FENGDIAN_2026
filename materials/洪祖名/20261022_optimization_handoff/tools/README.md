# tools 目录约定

本目录只放项目级、可复用的小型管理工具，不放训练代码、临时脚本或实验输出。

## 命名与边界

- 文件名使用小写英文和下划线，名称直接描述用途。
- 管理工具默认只读；会修改文件或 Git 状态的工具必须在文件头明确标注。
- Python 模型/训练工具归入 `optimization_control/` 对应模块，不放在这里。
- 一次性分析脚本完成后应迁入对应实验目录或删除；删除前必须取得用户许可。

## 当前工具

| 文件 | 作用 | 是否修改状态 |
|---|---|---|
| `project_git_status.ps1` | 汇总工作区、暂存区、本地提交和 remote | 否 |
| `package_optimization.py` | 组装本轮 ZIP、历史成果分卷与完整 SHA256 清单；拒绝覆盖，不上传 | 是，仅新交付目录 |
| `unpack_optimization.py` | 校验分卷、合并本轮 ZIP 并解压到新目录 | 是，仅新解压目录 |
