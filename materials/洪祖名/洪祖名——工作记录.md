优化部分—洪祖名

1. **单机 PPO 预研（T1）**

**目标**：独立打通「环境 → PPO → 评估 → 记录」的完整 RL 工具链。这是整个优化控制模块的技术底座。

**1.1 环境：SimplifiedTurbineEnv：NREL 5MW 简化单机环境（解析公式版，environments/simplified\_turbine\_env.py）具体如下：**

**物理模型**

Heier 1996 Cp 经验公式 + 叶尖速比耦合，P = 0.5·ρ·A·Cp(λ,β)·U³，限额定 5 MW

**动力学**

转速一阶惯性跟踪设定值，时间常数 τ = 5 s；桨距角直接累计并限幅

**观测**

5 维 [P, ω, β, U, P\_target]，除以尺度 [5e6, 1.2671, 25.0, 12.0, 5e6] 归一化到 [0,1]

**动作**

2 维 [Δβ, Δω]，区间 ±0.5 deg 与 ±0.1 rad/s

**回合**

200 步终止（合成任务终点）

**奖励**

-(跟踪误差² / (1e6)² + 0.1 · mean(归一化动作²))

**风速**

阶跃 8 → 9.5 m/s（第 100 步切换）

**目标功率**

当前风况最大可发功率的 80% → 65%（第 100 步切换），降载跟踪且始终可达

**1.2策略网络：Actor-Critic**

编写策略神经网络：**Critic网络负责计算：状态价值 V，actor\_mean网络负责：动作均值 μ，actor\_logstd负责：对数标准差**
（actor 与 critic **不共享主干**，各自独立的双隐层 MLP，每层 64 单元，激活函数用 nn.Tanh()。）

1.3 初步跑通PPO中的**Actor-Critic，并与Pcontroller进行对比**

**1.4 遇到的问题：**

**（1）目标功率必须物理可达：初版设 2.5 / 3.5 MW，但 8 / 9.5 m/s 风速下最大可发功率只有约 1.9 / 3.1 MW → 任务不可达，策略学不好。改为「当前风况最大可发功率 × 80%」后可解。**

**（2）训练与评估的观测归一化必须一致：初版用 NormalizeObservation wrapper 训练、却用原始观测评估 → 尺度不匹配，策略输出乱动作。改为环境内建固定归一化后，两侧一致。**

1. **随机风况与单机 v2（T1-W）**

**目标：把 T1 的确定性阶跃风换成可复现的随机湍流风，让单机 PPO 预研更接近真实场景。这是不依赖任何队友数据、可以独立推进的一条线。**

**参考turbsim的TurbSim User’s Guide v2.00.00，**

**风速(t) = 背景平均风 + Kaimal 湍流 + 事件(慢变化 / 阵风)**

**谱：S(f) = 4σ²L / U / (1 + 6fL/U)^(5/3) σ = TI · U**

**方法依据：TurbSim v2 用户指南 公式 Eq. 23**

**实现要点：**

**① 随机性：SeedSequence([seed, split\_id, worker, episode]) 四元组派生独立子流**

**split 映射 train=0 / validation=1 / test=2 → 训练与测试风天然不重叠**

**② 分层：stratum = (episode + worker) % 4，四个层各取一段均值覆盖 6–10 m/s**

**③ 事件：慢变化 = smoothstep 3φ²−2φ³，作用在回合 20%–80%，幅度 ±1 m/s**

**阵风 = 余弦脉冲 0.5(1−cos(2πφ))，幅度 +1.5 m/s、持续 40 s**

**④ 湍流：序列长度取回合的 8 倍（padding\_factor）避免首尾被 FFT 强制周期连接**

**频域乘 sqrt(n/dt · PSD/4)，DC 强制置零，Nyquist 单独用实数高斯**

**irfft 回时域后随机截取 601 点**

**⑤ 拒绝采样：越出 [0.5, 16] m/s 包络则重抽湍流（背景与事件参数保留），**

**最多 100 次，次数记入 rejected\_attempts；耗尽则报错，绝不裁剪序列**

**4．1新环境 StochasticTurbineEnv**

主要是将单位变为 **deg/s** 和 **rad/s²**，代表桨距变化率与转速参考变化率。

目前的**单步时序**：观测含当前目标 → 控制器动作 → 推进执行器并读取下一时刻风 → 算功率 → 对比**动作前已公布的目标**计算奖励 → 用新风生成下一目标 → 返回新观测。
