## 后续应放入的内容

- 优化器、PPO、控制闭环和评价指标说明；
- 训练/测试划分、随机种子、权重版本和评估轨迹；
- 失败训练、非收敛结果和不能外推的边界；
- 供材料引用的图表、报告和复现命令。

## 提交方式

1. 创建实验/材料 Issue，写清代码、数据、环境和指标；
2. 新的正式材料进入本目录，历史 `viz/` 文件不覆盖；
3. 在 `docs/evidence/` 建证据卡；
4. 由洪祖名确认优化和控制内容，再由至少一名其他成员复核；
5. 通过 PR 后再在集体材料中引用。

通用材料规则见 [`../README.md`](../README.md)，实验模板见 [`../../docs/templates/实验记录模板.md`](../../docs/templates/实验记录模板.md)。
