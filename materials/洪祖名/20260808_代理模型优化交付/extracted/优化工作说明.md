# 优化工作说明 — FLORIS 功率代理模型机器学习优化

> 日期：2026-08-08 | 提供：优化控制模块（Codex）
> 面向：袁夫达、厉今飞及全体项目组成员
> 数据源：FLORIS v4.6.6（GCH/CC 尾流模型），NREL 5MW × 3 台（间距 378m）

## 一、做了什么

针对现有 FLORIS 数据（GCH/CC 各 1224 组：风速 4~12 m/s × 风向 0~345° × 湍流强度 3 档），完成一轮系统的机器学习优化：

1. **基线复现**：用纯 numpy 前向加载厉今飞的 `.keras` 模型，指标完全复现（MAE 差 <0.1W）
2. **候选模型对比**：实现并评估 XGBoost、高斯过程回归（GPR）、改进 MLP（扩展特征）、两阶段模型（零功率分类+回归），统一 6 特征接口、分层 5-fold 交叉验证（seed=42）
3. **超参优化**：Optuna 贝叶斯搜索（TPE）
4. **残差分析与物理一致性检查**：误差热点定位、守恒/边界/单调性校验
5. **最终模型选定与导出**：XGBoost（xgboost 原生格式，可直接加载）

## 二、结果

### 模型对比（farm 功率，5-fold CV）

| 模型 | GCH farm R² | GCH farm MAE (kW) | CC farm R² | CC farm MAE (kW) |
|------|------------|-------------------|------------|------------------|
| 厉今飞 MLP（基线） | 0.99906 | 86.5 | 0.99871 | 103.1 |
| XGBoost（调参后） | **0.999978** | **7.79** | **0.999961** | **10.49** |
| GPR | 0.99993 | 14.9 | 0.99934 | 22.3 |
| two-stage | 0.99994 | 13.7 | 0.99996 | 12.8 |
| mlp_v2（调参后） | 0.9976 | 157→115 | 0.9977 | 154 |

**关键结论：**

1. **XGBoost 将全场功率预测误差降低约 11 倍**（farm MAE：GCH 86.5→7.79 kW，CC 103.1→10.49 kW），R² 均 >0.99996
2. **树模型/GPR 优于深度 MLP**：1200 组网格化确定性数据场景下，深度模型不占优（调参后仍差一个数量级）；深度路线留给后续 PINN 组
3. **误差热点在高风速段**（9-12 m/s，额定功率平台区）：GCH 该段 farm MAE 12.3 kW，是低风速段（2.9 kW）的 4 倍——这是后续提升数据精度的主攻区间
4. **GCH 比 CC 更好拟合**（R² 0.99998 vs 0.99996）：CC 尾流更复杂、物理更准但更难建模，两套数据建议都保留
5. **数据质量**：GCH 有 22 行、CC 有 4 行零功率样本（低风速+尾流遮挡），模型训练已剔除；最终模型推理建议 clip 到 [0, 5MW]
6. **物理一致性**：farm=Σturbine 守恒误差 1W（设计保证）；单调性抽查通过（gch 额定饱和区有 <kW 级抖动，无实际影响）

### 模型使用示例

```python
import numpy as np
from xgboost import XGBRegressor

def predict_power(wind_speed, wind_direction, turbulence_intensity, model_key="gch"):
    """输入风况，输出 3 台机功率(W) + farm 功率(W)"""
    theta = np.deg2rad(wind_direction % 360)
    x = np.array([wind_speed, turbulence_intensity, np.sin(theta), np.cos(theta),
                  np.sin(2*theta), np.cos(2*theta)], dtype=np.float32).reshape(1, -1)
    models = [XGBRegressor() for _ in range(3)]
    for i in range(3):
        models[i].load_model(f"final_models/{model_key}_turbine_{i+1}.json")
    t = np.array([m.predict(x)[0] for m in models])
    t = np.clip(t, 0, 5e6)  # 物理边界
    return t, t.sum()
```

## 四、给袁夫达的建议（数据侧）

1. **GCH vs CC 差异已量化**（见 `evaluation/model_comparison_cv.csv` 与残差图）：CC 数据更难拟合但物理更准。您提到的「优化函数提高数据精度」方向可从高风速段（9-12 m/s）入手，该段误差最大
2. **强烈建议补充偏航维度数据**：目前数据无偏航角，PPO 偏航控制无法训练。建议扩展为：
   - 每机独立偏航：`yaw_1, yaw_2, yaw_3`（推荐，RL 需要独立动作；数据量 ×N_yaw）
   - 或先统一偏航：`yaw` 单列（简化版，数据量 ×N_yaw）
   - 建议 yaw ∈ [−30°, 30°]，步长 5~10°；可先在 2~3 个代表风向/风速子集上扫，控制数据量
3. 数据生成时保留零功率行（不要提前删），两阶段模型（本交付含）可处理；生成脚本欢迎放入 `scripts/` 供复用

## 五、给厉今飞的建议（模型侧）

1. 您的 MLP 基线**已完整复现验证**（`scripts/keras_model.py` 无需 TensorFlow 即可加载推理）
2. 若追求精度，推荐直接使用本交付的 XGB 模型；若继续深度路线，参考 mlp_v2 的扩展特征（U³、三阶谐波）与调参结果（见 `optuna_results.txt`）
