# 厉今飞 · 个人材料目录

> 这里是厉今飞负责或需要审阅的基线数据与数据口径材料入口。目录责任不等于个人拥有全部原始数据或数据管道。

## 当前状态

当前 checkout 尚未登记一份明确归属于厉今飞的独立成品。此状态只表示材料索引尚未补齐，不表示外部位置没有材料。

## 后续应放入的内容

- 基线工况、数据字典和单位/量纲说明；
- 数据来源、获取日期、许可、版本和 SHA-256；
- 缺失值、清洗规则、划分方式和口径变更记录；
- 供其他领域和对外材料引用的可审阅表格、摘要或报告。

私有、敏感或未授权数据不得直接进入仓库。需要外置的数据，必须在仓库内留下 manifest 和可复核的来源说明。

## 提交方式

1. 创建数据/实验/材料 Issue，写清数据边界和用途；
2. 将可审阅源文件或导出物放入本目录；
3. 在 `docs/evidence/` 建证据卡，写清数据版本和口径；
4. 由厉今飞确认来源、单位和数字，再由至少一名其他成员复核；
5. 通过 PR 后再在集体材料中引用。

通用材料规则见 [`../README.md`](../README.md)，证据模板见 [`../../docs/templates/证据卡模板.md`](../../docs/templates/证据卡模板.md)。
