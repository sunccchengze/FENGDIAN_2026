# 三机串列双模型数据包（k-ω SST 与 k-ε）

同一几何、同一网格、同一工况（9 m/s，Ω = 1.070 rad/s）下的两套 Fluent 稳态 MRF 算例，
按相同方法提取的尾流与功率数据，可直接用于 PINN 代理模型的训练与交叉验证。

## 两套算例

| 项目 | k-ω SST | k-ε |
|---|---|---|
| 工程目录 | `fangji-2_files\dp0\FLTG\Fluent` | `fangji-2_files\dp0\FLTG-2\Fluent` |
| 结果文件 | `FLTG-2-04606.dat.h5` | `FLTG-1-04800.dat.h5` |
| 网格 | 1,055,511 单元 | 同一套网格 |
| 来流 / 转速 | 9 m/s / 1.070 rad/s | 同左 |

## 结果对比

| 指标 | k-ω SST | k-ε | 差异 |
|---|---|---|---|
| 三台合计推力 | 1054.6 kN | 1041.2 kN | −1.3% |
| **三台合计功率** | **5.80 MW** | **5.71 MW** | **−1.5%** |
| 第 1 台功率 | 2.39 MW | 2.32 MW | −2.7% |
| 第 2 台功率 | 2.10 MW | 2.09 MW | −0.5% |
| 第 3 台功率 | 1.31 MW | 1.30 MW | −0.9% |
| 盘面 TI（1/2/3 台） | 4.6 / 8.1 / 9.9 % | 3.5 / 5.0 / 5.7 % | −24 / −39 / −42% |

结论：总功率差异 1.5%，且主要来自第 1 台（−2.7%），下游两台只差 0.5%~0.9%；
湍流强度差异显著（24%~42%），但受网格分辨率限制，暂未传导到功率上。
另需注意：尾流偏窄（盘面平均亏损仅 4.4%），P2/P1 为 0.88，而工程参考为 0.45~0.55，
下游功率整体偏高约 80%，需加密尾流区网格（见对比报告第 6 章）。

## 数据约定

- **轴向速度**：`U_forward = −U_axial`，沿主流方向为正；转子区内的回流仍为负值（真实物理，勿取绝对值）；
- **单位**：长度 m、速度 m/s、力 N、功率 W（CSV 中另给 MW）、长度坐标 m；
- **坐标系**：世界坐标，转轴方向 (0, 0.096225, 0.99536)，轮毂高度 y = 81.333 m。

## 数据核对

- **推力**：逐面积分叶片压力，与 Fluent 自带力报告偏差 +0.7%；
- **盘面速度**：精确最近单元查找，重复提取可复现；
- **文档数值**：与 CSV 逐格核对，全部一致；
- **注意**：总功率是求和量，局部误差可能相互抵消（k-ω 早期版本单台功率偏差达 5.5%，总功率只变 0.03%），**请以单台数据为准，不要用总功率的稳定性判断数据是否正确**。

## 使用建议

- 两套数据字段完全一致，可直接拼接，并增加一个"湍流模型"特征列（0 = k-ω，1 = k-ε）；
- 一套作训练、一套作验证，可检验代理模型对湍流模型选择的敏感性；
- 中心线存在 ±2 m/s 锯齿（尾流区网格约 13 m），建议使用 `U_forward_smooth_m_s` 列或按 `n_cells` 筛点；
- 详细方法、差异分析与已知问题见 `三机串列_komega_vs_kepsilon_数据对比.docx`。
