**这份文档与 [`EVID-2026-003`](../../docs/evidence/EVID-2026-003_三机串列CFD数据可用性核查.md) 的关系**：它是田铭雨对我们核查发现的自述版本，两边的数字完全对得上（P2/P1 = 88%、盘面平均亏损 4.4%、网格 1,055,511 单元、k-ε 第 2 台盘面速度反而略高于第 1 台）。他本人在 §5.1 已写明「尾流偏窄，下游功率可能偏高」，并给出加密方案。

**三处需要与他对齐的口径**（已同步写进 EVID-2026-003 §8）：

1. 文档 §4.1 写「受上游尾流影响，第 2、3 台的功率依次降低，符合串列布置的基本规律」——这与同文档 §5.1「盘面平均速度亏损仅 4.4%」互相矛盾。事实是**第 2 台的盘面平均速度几乎没降**（k-ω 低 0.2%，k-ε 反而高 0.3%），功率下降主要来自推力下降。答辩不能说「符合规律」。
2. 文档 §5.2 给的验收带是「加密后 P2/P1 落到 **0.50～0.65**」；项目自己的 FLORIS GCH 在**同布局同来流**下给的是 **0.222**（TI 12% 时才 0.253）。两边差一个量级，**加密前必须先把验收带谈拢**，否则算出 0.45 会被他的带子判「不合格」，却会被 FLORIS 判「正常」。
3. 文档 §6 的网格无关性判据是「三台总功率与盘面平均亏损变化 < 2%」。**总功率是求和量**，他自己在 §5.2(3) 也写了「局部误差可能相互抵消，不能仅凭总功率稳定判断」——判据建议改成逐台 + 盘面亏损双指标。
