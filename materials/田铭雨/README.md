# 田铭雨 · 个人材料目录

> 这里是田铭雨负责或需要审阅的 CFD 仿真与物理建模材料入口。目录责任不等于个人拥有全部 CFD 代码或数据。

## 当前状态

当前 checkout 尚未登记一份明确归属于田铭雨的独立成品。此状态只表示材料索引尚未补齐，不表示外部聊天、电脑或其他位置没有材料。

## 后续应放入的内容

- CFD 工况、网格、边界条件和求解设置说明；
- 仿真输出的可审阅摘要、图表和报告；
- 物理假设、尾流模型、误差和适用范围说明；
- 供答辩或阶段总结引用的审阅版材料。

原始大数据不直接堆入材料目录。请先在研究记录中登记来源、版本、许可、大小和 SHA-256，材料目录只放可审阅源文件、报告或经过登记的导出物。

## 提交方式

1. 创建实验/材料 Issue，写清工况、输入、代码 commit、环境和输出；
2. 在本目录保存源文件或正式导出物；
3. 在 `docs/evidence/` 建证据卡，标明“真实/代理/演示/示意”口径；
4. 由田铭雨确认物理内容，再由至少一名其他成员复核；
5. 通过 PR 后再在集体材料中引用。

通用材料规则见 [`../README.md`](../README.md)，实验模板见 [`../../docs/templates/实验记录模板.md`](../../docs/templates/实验记录模板.md)。
