## 引言：为什么同事的叶片 AI 平台看起来“降维打击”？

经过我们派遣的**“五人专家团”**对 target 仓库的全面解剖（读取其 `frontend/src/` 中的全栈源码、CSS 设计令牌与 React 组件矩阵），我们一致认为：**该平台的网页设计之所以质感超群，绝非偶然，而是因为他们在底层落实了五大工业级设计与物理渲染精髓。**

下面是五位大师带回的**《深度偷师解析报告》**以及**如何将其移植入我们风电场偏航项目的具体指南**：

## 偷师本领一：【老塔】Edward Tufte · 学术研究类 UI 原子化设计 (ResearchUI.jsx)

### 1. 对方仓库做对了什么？
在 target 仓库 `src/components/ResearchUI.jsx` 中，我们发现了他们建立的一套高信噪比原子化科研 UI 组件规范：
- `<PageHeader>`：具备标准编码索引（如 `01 / RESEARCH WORKSPACE`）与中英文层级排布；
- `<Surface>`：统一用 `1px` 发丝高强线边框（`var(--line-strong)`）代替传统的阴影与卡片；
- `<MetricTile>`：将科研指标彻底解耦为数字正文、中英说明与备注底标，使用等宽字母型（`DM Mono`）呈现数字。

### 2. 对我们 8.23 组会项目的移植方案
- 我们可以将原先网页里简单的 `div.card` 全部升维为标准的 `<Surface>` 和 `<MetricTile>` 原子组件；
- 在每个子网页头部引用 `<PageHeader>` 布局，杜绝任何廉价模板感，建立纯学术工作台的气场。

## 偷师本领二：【老乔】Steve Jobs · 气动探针流场与势流避障互动背景 (AerodynamicBackground.jsx)

### 1. 对方仓库做对了什么？
这是一项堪称“神作”的前端视觉工程！他们没有直接挂载被动的背景视频，而是利用 HTML5 Canvas 编写了 **`AerodynamicBackground.jsx` 交互式流体力学气动背景**，具备 5 大黑科技：
1. **惯性阻尼墨绿探照光斑 (Damped Follower Spotlight)**：鼠标划过时，底层有 LERP 滤波追踪的主题色光斑平滑跟随；
2. **气动流线与势流避障偏转 (Dipole Potential Flow Streamlines)**：多条模拟风洞进气的流线，当遇到指尖（或障碍物点）时会自动按照气流不可压缩偶极子势流方程向两翼偏转绕流；
3. **48px 几何网格近场节点感应高亮 (CFD Mesh Node Illumination)**：绘制底层 48px CFD 计算网格，当触点靠近时，周遭十字路口节点自动亮起发光；
4. **压力波声学涟漪 (Acoustic Shock Waves)**：点击时生成向外衰减扩散的流体压力同心涟漪；
5. **视口离屏自动休眠 (0% CPU 占用)**：当用户滚动离开或切换页面，`IntersectionObserver` 自动暂停循环，保障电池寿命。

### 2. 对我们 8.23 组会项目的移植方案
- **历史试验结论**：曾制作独立 Canvas 原型验证网格与指针动效，但该页面不由 FLORIS 数据驱动，现已退役并从仓库删除。
- 可保留的工程经验已经用于 `site/index.html` 的背景交互和 `site/3d_farm.html` 的动画循环；组会只展示可追溯到数据契约的现役页面。

## 偷师本领三：【李博杰】现代 AI Agent · 纯静态模块化路由与浏览器推理架构

### 1. 对方仓库做对了什么？
对方仓库采用 `React 19 + Vite + Tailwind 4 + ONNX Web` 构建了现代组件矩阵：
- 利用 `onnxruntime-web` 使得端侧可以直接运行神经网络模型推理，**无服务端延迟**；
- 每个页面（Explore, Methodology, Optimize, Predict, UQ）专注一项工程论证，职责完全独立且通过上下文无缝解耦。

### 2. 对我们 8.23 组会项目的移植方案
- 我们现役的 `site/` 15 个静态网页已经具备“无后端、纯浏览器极速推理（`RegularGridInterpolator` <0.5 ms）”的内核；
- 吸取其路由划分理念，我们在主页（`index.html`）和各专题页之间建立了更丝滑的高能锚点导览，使数据契约和可达域物理推演呼应一致。

## 偷师本领四：【老达】Leonardo da Vinci · 工业设计级高级色调令牌与流体渐变

### 1. 对方仓库做对了什么？
解密对方的 `index.css` 后，我们发现了他们美学品质的核心——**极高品味的工业色盘与动画缓动函数**：
- **颜色令牌**：`--paper: #e6ebe1`（带着柔和工程青绿底色的纸质灰白）、`--teal: #86b9aa`（高级学术青灰）、`--yellow: #e7c85b`（黄金突显色）、`--rust: #c5684a`（砖红警告对比）；
- **缓动光影**：为所有背景切换配置了高级贝塞尔函数 `transition: background-color 0.45s cubic-bezier(0.16, 1, 0.3, 1)`，使视觉交互带来“工业仪表灯光亮起与熄灭”的沉浸感。

### 2. 对我们 8.23 组会项目的移植方案
- 将我们项目现有的莫兰迪主色与对方的 `--paper (#e6ebe1)` 和 `--teal (#86b9aa)` 质感进一步交融；
- 在网页与演示幻灯片中注入对应的高级 Cubic-Bezier 动效曲线，彻底消除廉价的瞬间生硬跳帧。

## 偷师本领五：【老弗】Paul Fleming · 3D 专业几何观测与网格透视视角 (BladeViewer3D.jsx)

### 1. 对方仓库做对了什么？
在 `BladeViewer3D.jsx` 中，对方使用 React Three Fiber（R3F）构建了工程零件的高级渲染模式：
- 具备一键“网格透视 / 实心光影（Wireframe / Solid）”即时切换功能；
- 预置了正交俯视与 30° 几何轴向视角，能够随时剖析工业部件内部网格拓扑。

### 2. 对我们 8.23 组会项目的移植方案
- 我们可以将这一技术理念融合到我们现有的 **`3d_farm.html`** 与 **`3d_surface.html`** 中；
- 汇报时向导师展示我们的三维风场既看得到实际轮毂旋转，也能切换观察底层的有限元/切片网格坐标。
