## 哪些内容不能直接放进这里

- CFD 原始输出、代理模型训练数据、PPO 权重和控制实验结果：先进入对应领域的证据/研究记录，不把材料目录当数据仓库；
- 未审阅的数字、截图或“最终版”文件：先建 Issue，补来源、代码 commit、环境和适用范围；
- `viz/` 封板资产：不直接 `mv`、批量重命名或覆盖；如果需要在材料中使用，只增加索引和引用关系。

## 新材料提交规则

1. 在材料 Issue 中写明对象、用途、截止时间和格式；
2. 源文件和生成文件进入本目录，提交快照写明日期和对象；
3. 每个关键数字链接 `docs/evidence/` 的证据卡；
4. 涉及其他成员的内容，填写内容主责人和审阅人；
5. 通过 PR 后再作为正式材料使用。

通用规则见 [`../README.md`](../README.md)。
