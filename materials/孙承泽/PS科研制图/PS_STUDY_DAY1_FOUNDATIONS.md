# 孙承泽 · Photoshop 科研制图零基础通关手册（Day 1 基础与规范）

> **学习目标**：建立科研期刊与大创答辩专用的 PS 工作流认知，掌握 300 DPI 画布设置、RGB/CMYK 色彩模式、标尺栅格系统，以及组长挑不出任何毛病的**五层图层组标准结构**。

---

## 一、 必须牢记的三个核心概念（绝不踩坑）

### 1. 分辨率（DPI / PPI）
- **网页/屏幕展示**：72 DPI（像素密度低，放大会模糊）；
- **学术论文（Nature / AIAA / 顶刊）**：**必须 300 DPI**（印刷级清晰度，矢量线条放大不毛糙）；
- **大创展板（A0 Poster）**：**200 ~ 300 DPI**（尺寸 841mm × 1189mm，300 DPI 下像素约为 $9933 \times 14043$）。

### 2. 色彩模式（Color Mode）
- **RGB（推荐）**：专为屏幕、投影仪、网络评审设计。色域更广，我们的莫兰迪雾蓝（`#6B8CAE`）与鼠尾草绿（`#8AA17A`）在 RGB 模式下最通透；
- **CMYK**：专为实物喷绘印刷机设计。如果之后真要去打印店打喷绘海报，最后导出时转换为 CMYK。

### 3. 智能对象（Smart Object）—— PS 的最核心灵魂
- **普通图层**：缩放一次就丢失像素变模糊（不可逆）；
- **智能对象（右键 -> 转换为智能对象）**：封装了原始数据，无论放大缩小 100 次，清晰度永远 100% 保持！
- **铁律**：所有风机轮廓、SVG 矢量箭头、导出的流场图，放入 PS 后**第一件事就是转为智能对象**！

## 二、 组长挑不出毛病的「五层图层组标准架构」

在 Photoshop 中新建文档后，按 `Ctrl+G` 建立 5 个图层组，并按如下标准严格命名（让任何拿到你 PSD 的人一眼看出顶级规范）：

```text
📁 A0_Poster_or_Figure.psd
├── 📁 01_Labels_and_Typography     [文字层：保持文本可编辑，宋体-简标题 + 无衬线数据]
├── 📁 02_Annotations_and_Vectors   [标注层：5D=630m 间距线、偏航角度弧、箭头]
├── 📁 03_Turbine_SmartObjects      [设备层：NREL 5MW 风机机舱、塔筒、转子矢量智能对象]
├── 📁 04_Flow_Field_Rasters        [流场层：FLORIS / CFD 导出的高精度速度云图位图]
└── 📁 05_Background_and_Grid       [背景层：莫兰迪暖米色底 #F8F6F0 + 1px 细发丝参考线]
```

## 三、 第一天必练快捷键清单（肌肉记忆）

| 快捷键 | 功能 | 科研制图高频场景 |
| :--- | :--- | :--- |
| **`V`** | 移动工具 | 拖动风机、对齐卡片，按住 `Alt` 拖动可快速复制 |
| **`T`** | 文字工具 | 输入论文参数、风机编号 $T_1 \sim T_9$ |
| **`P`** | 钢笔工具 | 绘制平滑的偏转尾流中心线与角度标注 |
| **`Ctrl + T`** | 自由变换 | 旋转上游风机至 $+25^\circ$ 偏航角，按住 `Shift` 等比例缩放 |
| **`Ctrl + G`** | 图层编组 | 整理图层组，保持 PSD 干净整洁 |
| **`Ctrl + Alt + Shift + N`** | 新建空白图层 | 快速创建图层绘制标注 |
| **`Ctrl + R`** | 显示/隐藏标尺 | 拖出辅助参考线，确保所有图表左对齐、右对齐 |

## 🎯 Day 1 上机小任务（30 分钟）
1. 打开 Photoshop，新建画布：宽度 1920 像素，高度 1080 像素，分辨率 300 像素/英寸，颜色模式 RGB 8位，背景内容选择自定义米白色（`#F8F6F0`）；
2. 建立上述 5 个图层组；
3. 从标尺拖出 4 条参考线，在画布四周留出 80px 的等宽边距；
4. 保存工程文件为 `day1_template.psd`。
