# 多 Agent 协同与双盲红蓝对抗架构规范 (Multi-Agent Architecture)

> **适用项目**：风电场偏航优化可视化平台与大创答辩工程
> **设计目标**：将传统的“单 Agent 角色切换”升级为“专业分工、独立沙箱、双盲对抗审查、基于制品契约”的现代化多 Agent 协作体系。

## 二、 三大核心协作机制

### 1. 物理/上下文隔离（Context Isolation）
- 各工兵 Agent 拥有独立的任务边界与专注上下文，避免“既写流体力学偏微分方程、又写前端 CSS 动效”导致的上下文长度溢出与注意力漂移。

### 2. 双盲否决权审查（Adversarial Veto Gate）
- 任何交付给承泽的成果物（PPTX / PSD / HTML / 论文图表），必须在交付前经由独立审查视角审计：
  - **审查项 A（老塔审查）**：是否存在悬浮卡片、Emoji 装饰、彩色气泡等 AI 模板痕迹？
  - **审查项 B（老贝审查）**：输出的功率数值、偏航方向（`/` 导向）是否符合流体第一性原理？
  - **审查项 C（老芒审查）**：答辩评委如果在此处追问，能否给出严谨的数学或实测证据？
- 只要有 1 项未通过，内部自动打回修正，不把半成品暴露给用户。

### 3. 基于“标准制品（Artifacts）”的契约化交接
- Agent 之间禁止传递模糊口头指令，统一以文件契约交互：
  - 流场数据契约：`fields_array/*.npz`
  - 气动性能契约：`cases_array.csv`
  - 设计规范契约：`site/DESIGN.md`
  - 演示文稿契约：`王牌PPT.pptx`
